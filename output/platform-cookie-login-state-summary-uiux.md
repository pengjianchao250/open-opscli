# 平台登录态接口摘要文案规范

日期：2026-06-11

## 文案目标

使用“登录态”替代“Cookie”，降低调用者对敏感字段形态的关注，同时保留接口真实用途。

## 冻结文案

接口摘要：

```text
读取用户在指定平台的登录态
```

## 相关文案约束

错误说明：

```text
OPS 平台登录态接口未授权，请先刷新 OPS/MCP 认证；这不是 Amazon 登录态缺失。
```

缺失说明：

```text
当前用户未保存该平台登录态。
```

## 禁止文案

以下文案不作为新摘要使用：

```text
读取当前用户在指定平台的 Cookie
读取当前用户在指定平台保存的 Cookie
读取平台 Cookie content
```

## 敏感信息边界

Agent 回复、报告和 MCP 输出不得展示：

- cookie
- 平台登录态原文
- `content`
- headers
- payload
- cURL 命令
- storage state
