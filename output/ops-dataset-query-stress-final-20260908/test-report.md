# ops-dataset-query 自然语言规划器测试报告

> 测试完成时间：2026-09-09（Asia/Shanghai）｜Skill 版本：1.4.6

## 领导结论

本轮 P0、P1 已修复，最终没有发现残留的高优先级规划缺陷。规划器能够稳定理解领导常用的“按部门看收入和毛利、环比上月、排除某部门”等复合请求，正确保留全部指标、时间对比、分组和排除条件，不会把否定筛选反转，也不会因复合名称中的国家、部门或品牌子串产生额外筛选。

全量基础验收覆盖当前账号 78/78 个数据集、3312 个授权字段，359/359 条通过。完整查询单元测试 719/719，Skill 与打包测试 13/13；editable dev 安装、静态编译和 diff 校验均通过。

## 代表性验收

请求“获取8月份各部门的收入及毛利情况，并环比7月数据，排除部门：范泰克-体系外”返回 `planned`：

- 数据集：即时综合数据集。
- 维度：部门。
- 指标：销售额、毛利；“收入”按数据集口径映射为“销售额”并披露。
- 主周期：2026-08-01 至 2026-08-31；对比期：2026-07-01 至 2026-07-31。
- 排除条件：部门 `!= 范泰克-体系外`。

## 剩余风险

当前保留三个 P2，不影响查询安全：英文组件枚举短语 `show available` 会安全澄清但不能直接生成枚举模板；“傲创-美国和傲创-加拿大渠道”这类值列表在字段标签前的表达会安全澄清；部分冲突请求虽已阻止执行，但原因码仍可从通用未匹配细化为极性冲突。自然语言直接写技术字段时，规划器现在会阻止残缺模板并明确提示使用重复的 `--field` 参数，不再作为残余问题。

## 结论边界

全量矩阵验证规划合同，不批量执行生产业务查询，避免无必要的大范围数据读取。机器判分覆盖状态、选表、字段完整性、时间、排序、Top N、环比、快照和组件筛选；高风险代表请求另用真实 CLI 规划复验。
