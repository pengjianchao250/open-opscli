# 新品计算器逻辑精简 Proposal

## 目标

- 利润相关成本费用由 CLI 自动填 `0`，不再要求用户填写。
- 指定二区默认使用 `zone_1_2`（美东+美西）。
- `calculator detail` 改为完整展示 `taskDetails.allPlans` 费用方案表。

## 改动

- 调整成本字段必填与默认值。
- 调整指定二区默认枚举及中文说明。
- 用只读费用方案表替换自发货/FBA/WFS 毛利结果表。
- 同步新品计算器 Skill 参考说明和待归档变更记录。

## 约束

- 不修改 Polaris API。
- 不实现方案切换、保存或切换请求。
- 不新增测试用例。
- 不运行 type-check、eslint 或格式化检查。
- 不修改本次需求之外的文件。

## 验收

- 新草稿成本字段为 `0`，对应校验不再阻塞。
- `two_zone_combine` 默认为 `["zone_1_2"]`。
- 详情展示全部 `allPlans`、全部 `schemes` 及费用区间。
- 表格不包含单选和切换功能。
