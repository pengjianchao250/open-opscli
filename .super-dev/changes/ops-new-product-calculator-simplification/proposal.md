# 新品计算器逻辑精简 Proposal

## 目标

- 利润相关成本费用由 CLI 自动填 `1`，避免 `0` 导致后端计算失败；新版 `填写表格.csv` 删除整个成本费用分组，`填写表格-旧版.csv` 备份旧结构并弃用。
- 包装和箱规缺失时保持为空，提供官方参考选项并由 Skill 分轮询问到必填项完整。
- 指定二区默认使用 `zone_1_2`（美东+美西）。
- `calculator detail` 改为完整展示 `taskDetails.allPlans` 费用方案表。

## 改动

- 调整成本字段必填与默认值，草稿生成和提交阶段都把隐藏字段统一覆盖为非零占位值 `1`。
- 生成新版 `填写表格.csv` 时过滤成本费用分组，同时生成带弃用说明的完整 `填写表格-旧版.csv`；`draft.json` 仍保留完整接口字段。
- 调整指定二区默认枚举及中文说明。
- 在草稿使用说明中区分单件 SKU 包装与 FBA 入库外箱，参考项不自动代入；移除 Skill 中可直接复制的虚构物流数据。
- Skill 每轮只追问仍缺失或无效的字段，参考模板、外箱数据和单箱数量均需用户确认。
- 启用新品计算器 Skill 的 source、wheel、binary、binary_full 发行目标。
- 用只读费用方案表替换自发货/FBA/WFS 毛利结果表。
- 同步新品计算器 Skill 参考说明和待归档变更记录。

## 约束

- 不修改 Polaris API。
- 不实现方案切换、保存或切换请求。
- 只调整本需求相关测试。
- 不运行 type-check、eslint 或格式化检查。
- 不修改本次需求之外的文件。

## 验收

- 新草稿成本字段为 `1`，对应校验和后端计算不再阻塞。
- 历史草稿即使保存了 `0`，提交 payload 也会改为 `1`。
- 新生成或刷新的 `填写表格.csv` 不包含成本费用字段。
- 同目录生成包含完整字段且标记弃用的 `填写表格-旧版.csv`，校验和提交不读取该文件。
- 包装、重量和箱规未返回时保持空白；使用说明只展示不自动填入的官方参考。
- Skill 持续补问到所有必填字段有效，且不会混用 SKU 包装和 FBA 入库外箱。
- 更新后的 Skill 会进入全部发行目标。
- `two_zone_combine` 默认为 `["zone_1_2"]`。
- 详情展示全部 `allPlans`、全部 `schemes` 及费用区间。
- 表格不包含单选和切换功能。
