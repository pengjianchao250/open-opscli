# 分析方法

## 目标判断

先根据数据判断本次广告优化目标，不要直接套固定动作：

- 毛利或毛利率为负 / 偏弱：优先修复利润。
- ACOS 高或广告费占总销售偏高：优先降低广告费占比、提升投产。
- ACOS 可控但销售额、点击或曝光下滑：优先扩大有效流量。
- 总销售稳定且广告费占比下降：关注自然流量沉淀和结构稳定性。
- ROAS 高但量小：适合小步放量，不代表整体结构健康。

## 漏斗诊断顺序

必须按以下顺序诊断：

1. 曝光：曝光量、Reach（如有）、预算限制、竞价竞争力、关键词/投放覆盖。
2. 点击：点击量、CTR、CPC。
3. 转化：广告订单、广告销售额、CVR、CPA（如有）、ACOS、ROAS。
4. 销售与利润：总销售额、毛利、毛利率、广告费占总销售。
5. 结构与预算：渠道、大组、小组、广告类型、类目、ASIN、活动。

不要跳过前面的层级，直接根据 ACOS 或 ROAS 下结论。

## 问题归因

统一使用以下归因：

- 量级问题：曝光或点击不足。
- 流量质量问题：有点击但转化弱，关键词、搜索词或投放对象可能不精准。
- Listing 承接问题：价格、评价、优惠、主图、A+、配送、库存、成本或产品竞争力不足。
- 广告结构问题：自动/手动、SP/SB/SD、广泛/词组/精准、商品投放或活动归属混乱。
- 预算分配问题：高效活动预算不足，低效活动消耗过多。

如果本质是 Listing 或产品竞争力问题，要直接指出，不要把问题都归因到广告。

## 逐行诊断规则

默认阈值来自 `thresholds.default.json`，用户可在分析前调整。规则逻辑如下：

- 毛利率为负：立即执行；建议收缩预算或暂停低效活动，并检查 Listing 和产品经济模型。
- 毛利率低于弱毛利阈值且广告费占比偏高：归因为预算分配或产品承接风险。
- ACOS 高于高风险阈值：控量、降价、排查高花费低转化流量。
- 点击达到样本阈值但 CVR 低：归因为流量质量或 Listing 承接问题。
- 高曝光但 CTR 低：优先检查主图、价格、评价、标题卖点和投放相关性。
- ACOS 好、CVR 好且毛利可承接：可小幅放量或转入独立收割活动。
- 广告费环比上升但 ACOS 同时恶化：暂停继续扩预算，定位新增花费来源。
- 广告销售额下滑但 ACOS 仍可控：检查核心词排名、预算断档和历史高转化流量流失。

低样本行不要激进停投或大幅提价，除非已经出现明确亏损、高 ACOS 或点击后不转化。

## 动作建议

立即执行：
- 降低高花费、高 ACOS 活动或 ASIN 的出价/预算。
- 对达到点击样本仍无转化的搜索词、活动或投放对象做降价、暂停或否定。
- 将高转化搜索词或投放对象转入手动精准 / 独立收割活动。
- 将预算从亏损、低毛利、低转化对象转向高毛利、转化稳定对象。
- 同步检查价格、优惠、评价、主图、A+、配送、库存和成本。

短期观察：
- 样本不足但表现不差的对象先观察。
- 小样本高效对象可先提高预算或出价 10%-20%，观察 7 天稳定性。
- ACOS 预警但毛利可承接的对象，先看搜索词和活动结构再决定是否收缩。

暂不建议：
- 不因单期 ACOS 高就机械停投，要结合毛利、排名价值和业务目标。
- 不因 ROAS 高就盲目放量，样本太小需要先验证稳定性。
- 不在 Listing 或产品竞争力明显弱时继续单纯加广告预算。

## 输出风格

默认中文、结构化、可执行：

1. 整体判断。
2. 分环节诊断：曝光、点击、转化、投产与成本、结构与预算。
3. 主要问题归因，按轻重排序。
4. 具体优化建议，分为立即执行、短期观察、暂不建议调整。
5. 补充提醒：Listing、价格、评价、促销、库存、配送、成本等非广告因素。

如果已经生成 Excel，聊天回复只保留关键摘要和文件链接，详细表格放在工作簿中。
