## 生成来源及要求

- 生成来源：根据 `packages/operation-frontend-core/src/pages/aiMethodCard/detail.vue` 当前生成的 AI 方法卡配置结构整理，并结合 `packages/operation-frontend-core/src/api/types/ai/methodCard.ts` 校准字段类型。
- 生成要求：正文只描述字段本身的业务含义、类型、可选值和嵌套结构，不描述字段来自页面哪个区域，不记录请求体、接口路径、保存链路或页面交互实现。
- 结构边界：本文档只对齐当前 `detail.vue` 与 `src/api/types/ai/methodCard.ts` 暴露的 `AiMethodsCard` 契约，不与同目录 `prd.ts` 中的历史 `PlaybookCard` 示例混用。
- 更新要求：当 `detail.vue` 中生成的配置字段发生新增、删除、改名、类型变化或可选值变化时，需要同步更新本文档。

本文档说明 AI 方法卡配置对象的字段含义、类型和可选值。更完整的运行态输出示例见同目录 `卡片输出示例.html`。

## 顶层字段

| 字段                 | 类型                                                                               | 字段说明                                                       |
| -------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `id`                 | `string`                                                                           | 方法卡唯一标识，用于定位一张方法卡。                           |
| `name`               | `string`                                                                           | 方法卡名称，用于展示、检索和识别配置。                         |
| `description`        | `string`                                                                           | 方法卡描述，用于说明方法卡用途、适用场景和输出目标。           |
| `scope`              | `BusinessScope`                                                                    | 方法卡适用的业务范围，用于推荐、筛选和场景匹配。               |
| `inputIntent`        | `AiMethodsCardTag[]`                                                               | 可触发该方法卡的用户意图或问题表达。                           |
| `requiredEntities`   | `AiMethodsCardTag[]`                                                               | 运行方法卡前必须识别或提供的业务实体。                         |
| `supportedScenarios` | `AiMethodsCardTag[]`                                                               | 方法卡支持处理的业务场景标签。                                 |
| `analysisView`       | `AiMethodsAnalysisView[]`                                                          | 方法卡关联的分析视图摘要，用于引用外部分析视图候选或已选视图。 |
| `knowledgeScopes`    | `AiMethodsCardTag[]`                                                               | 方法卡分析时需要参考的知识范围。                               |
| `analysisSteps`      | `AiMethodsCardTag[]`                                                               | 方法卡的分析执行步骤；数组顺序表示步骤顺序。                   |
| `outputContract`     | `{ content: Array<{ name: AiMethodsReportContent }>; charts: DefaultChartType[] }` | 方法卡输出结果契约，用于约束报告内容和默认图表 / 组件类型。    |
| `qualityRules`       | `AiMethodsCardTag[]`                                                               | 方法卡输出质量规则，用于约束结论、诊断和建议的生成标准。       |
| `userId`             | `string`                                                                           | 方法卡归属用户 ID，用于归属、权限或过滤。                      |

## `scope` 字段

| 字段             | 类型       | 字段说明                                                                              |
| ---------------- | ---------- | ------------------------------------------------------------------------------------- |
| `platforms`      | `string[]` | 适用平台列表。当前可选值：`amazon`。                                                  |
| `sites`          | `string[]` | 适用站点列表。当前可选值：`us`、`ca`、`uk`。                                          |
| `categories`     | `string[]` | 适用类目列表。当前可选值：`furniture`。                                               |
| `scenarios`      | `string[]` | 适用业务场景列表。当前可选值：`ad_optimization`、`ad_anomaly_diagnosis`、`ad_alert`。 |
| `businessStages` | `string[]` | 适用产品阶段列表。当前可选值：`new_product`、`growth`、`stable`。                     |

## 标签型数组字段

以下字段结构相同，类型均为 `AiMethodsCardTag[]`：

- `inputIntent`
- `requiredEntities`
- `supportedScenarios`
- `knowledgeScopes`
- `analysisSteps`
- `qualityRules`

数组元素结构：

| 字段   | 类型     | 字段说明                                       |
| ------ | -------- | ---------------------------------------------- |
| `name` | `string` | 标签、实体、场景、知识范围、步骤或规则的名称。 |

## `analysisView` 字段

类型：`AiMethodsAnalysisView[]`

| 字段          | 类型                  | 字段说明                                     |
| ------------- | --------------------- | -------------------------------------------- |
| `id`          | `string`              | 分析视图唯一标识。                           |
| `name`        | `string`              | 分析视图名称。                               |
| `description` | `string \| undefined` | 分析视图说明；候选列表接口可能不返回该字段。 |

## `outputContract` 字段

| 字段      | 类型                                      | 字段说明                                     |
| --------- | ----------------------------------------- | -------------------------------------------- |
| `content` | `Array<{ name: AiMethodsReportContent }>` | 报告内容配置，用于约束输出报告包含哪些部分。 |
| `charts`  | `DefaultChartType[]`                      | 默认图表 / 组件配置，用于约束默认展示形态。  |

### `outputContract.content[].name` 可选值

| 值                           | 含义       |
| ---------------------------- | ---------- |
| `overall_conclusion`         | 整体结论   |
| `keyword_matrix`             | 关键词矩阵 |
| `diagnosis`                  | 诊断       |
| `opportunity_identification` | 机会识别   |
| `optimization_suggestions`   | 优化建议   |
| `risk_warnings`              | 风险提醒   |

### `outputContract.charts[]` 可选值

当前页面仅暴露以下默认图表 / 组件类型：

| 值             | 含义       |
| -------------- | ---------- |
| `bar_basic`    | 基础柱状图 |
| `line_basic`   | 基础折线图 |
| `pie_basic`    | 基础饼图   |
| `detail_table` | 明细表     |
