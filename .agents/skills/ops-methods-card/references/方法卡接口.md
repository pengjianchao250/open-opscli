# 方法卡接口参考

来源：`E:/code/work/operation-frontend - 1/packages/operation-frontend-core/src/pages/aiMethodCard/prd/AI-方法卡接口.md` 与 `src/api/modules/ai/methodCard.ts`。

Skill 不直接请求后端接口，必须通过 `opscli methods-card` 命令访问。

## 列表接口

CLI：

```bash
opscli methods-card list --keyword "<keyword>" --page 1 --per-page 100 --pretty
```

后端接口：

- Method：`GET`
- Path：`/api/v1/ai/method-card`
- 认证：`Authorization: Bearer <token>`

常用查询参数：

| 参数 | 说明 |
| --- | --- |
| `keyword` | 匹配 `card_name` 或 `card_code` |
| `page` | 页码，最小 1 |
| `per_page` | 每页条数，1 到 100 |
| `type` | 类型筛选：1 官方 / 2 团队 / 3 个人 |
| `status` | 状态筛选：1 可用 / 2 草稿 / 3 已废弃 |
| `platforms` | 平台名称筛选 |
| `sites` | 站点名称筛选 |
| `categories` | 类目名称筛选 |

列表响应核心字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 方法卡 ID |
| `card_code` | 方法卡编码 |
| `card_name` | 方法卡名称 |
| `status_text` | 状态文案 |
| `type_text` | 类型文案 |
| `scenarios` | 适用场景 |
| `platforms` | 适用平台 |
| `sites` | 适用站点 |
| `categories` | 适用类目 |

## 详情接口

CLI：

```bash
opscli methods-card detail <card_id> --pretty
```

后端接口：

- Method：`GET`
- Path：`/api/v1/ai/method-card/{id}`
- 认证：`Authorization: Bearer <token>`

详情响应核心结构：

```json
{
  "card": {
    "id": 12,
    "card_code": "PBK-001",
    "card_name": "方法卡示例",
    "status": 1
  },
  "detail": {
    "id": 1,
    "card_id": 12,
    "content": {}
  }
}
```

`detail.content` 是方法卡分析规范主体，字段说明见 `references/卡片.md`。
