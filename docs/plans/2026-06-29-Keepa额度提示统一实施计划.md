# Keepa 额度提示统一实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Keepa 查询完成后的用户回复展示 MCP 每日调用额度，并与卖家精灵保持一致。

**Architecture:** 保留现有 MCP 限额中间件和 `keepa_run` 返回结构，只修改 Keepa CLI/MCP Skill 的展示契约。测试直接读取内置 Skill 模板，确保两种调用语境都要求展示顶层 `quota`，同时继续隐藏 Keepa 账号级 token 信息。

**Tech Stack:** Python 3.10+、pytest、Markdown Skill 模板

## Global Constraints

- 不修改 `keepa_run` 参数和 MCP 返回结构。
- 只展示 MCP 每日调用次数 `limit`、`used`、`remaining`、`reset_at`。
- 不展示 Keepa API Key、账号来源、`tokensLeft` 或 `tokensConsumed`。
- `keepa_job_status` 和 `keepa_export` 不重复提示额度。
- 保留用户现有的 `opscli/mcp/configs/mcp-quota.json` 工作区改动，不纳入本次提交。
