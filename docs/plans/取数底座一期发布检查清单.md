示例：

```bash
curl -X POST https://https://ops.api.qa.aukeyit.com/api/v1/data-metrics/datasets/skill/publish \
```

## 六、常见风险

### 6.1 `manifest` 仍返回 `v0.0.0`

原因：

- 发布未真正执行
- 发布环境与 CLI 使用环境不一致

处理：

- 先确认 `ops_url`
- 再确认发布接口实际写入的环境

### 6.2 `skills status` 返回 404

原因：

- `ops_url` 指向的环境未部署 Skill 接口

处理：

- 检查 `~/.config/opscli/config.ini`

### 6.3 `skills upgrade` 无法识别更新

原因：

- 本地版本文件仍是旧值
- 远端 manifest 未更新

处理：

- 先执行 `skills status --pretty`
- 再确认 `remote_manifest.version`

## 七、建议执行顺序

1. 先跑一致性脚本
2. 再执行 `publish`
3. 再读 `manifest`
4. 再用 `opscli skills status/upgrade` 验证
5. 最后补联调记录
