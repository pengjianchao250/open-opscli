### 2. 发布 manifest 版本

执行：

```bash
python - <<'PY'
from opscli.auth import AuthClient, OPS_URL
import httpx

token = AuthClient().get_token('ops')
resp = httpx.post(
    f"{OPS_URL}/v1/data-metrics/datasets/skill/publish",
    headers={'Authorization': f'Bearer {token}'},
    json={
        'version': 'v0.1.0',
        'description': 'phase1 first local publish for dataset-fields skill'
    },
    timeout=30,
    follow_redirects=True,
)
print(resp.status_code)
print(resp.text)
PY
```

预期：

- 返回业务 `code = 200`
- 返回 `version / dataset_count / field_count / published_by`

### 9. 带筛选条件和分组的查询成功样本

执行：

```bash
cat >/tmp/opscli-query-grouped.json <<'JSON'
{
  "tableId": 1103,
  "query": {
    "select": [
      { "expr": "ds_e93be345cfa1.country_name", "alias": "f_dim001" },
      { "expr": "ds_e93be345cfa1.price", "alias": "f_metric001", "aggregation": "SUM" }
    ],
    "where": {
      "operator": "AND",
      "conditions": [
        { "field": "ds_e93be345cfa1.country_name", "operator": "in", "value": ["美国"] },
        { "field": "ds_e93be345cfa1.date_id", "operator": "between", "value": ["2022-01-01", "2022-03-31"] }
      ]
    },
    "groupBy": ["f_dim001"],
    "orderBy": [
      { "expr": "f_metric001", "desc": true }
    ],
    "limit": 5,
    "offset": 0
  }
}
JSON

opscli query run --payload /tmp/opscli-query-grouped.json --pretty
```

预期：

- 返回 `success = true`
- 返回 1 行聚合结果
- `f_dim001 = 美国`
- `f_metric001` 为聚合后的订单金额

注意：

- `orderBy` 必须使用：
  - `{ "expr": "f_metric001", "desc": true }`
- 不能误写成：
  - `{ "field": "f_metric001", "direction": "DESC" }`
