# 卖家精灵全部场景分页实施方案

日期：2026-09-28

## 目标

让每个卖家精灵场景都有明确的采集语义：单页、可分页全量、官方文件透传、任务详情分页或单报告。实现按场景合同选择请求字段、响应解析、上限、行唯一键和导出策略，避免把选产品的 `data.items/data.total`、ASIN 判重或 2,000 条上限套到其他场景。

## 采集能力分层

| 能力 | 场景 | 实施结论 |
| --- | --- | --- |
| `page` | 全部列表和报告场景 | 保持现有默认行为，一次请求和现有导出格式不变 |
| `all` 第一批 | 选产品、选竞品 | 采用网页已确认的 100 条页大小和最多 2,000 条；各自使用独立响应解析器、行键和检查点 |
| `all` 第二批 | 关键词挖掘 | 使用 `pageNum/pageSize`，网页允许至少 3,705 条；上限暂定为场景合同配置，不能写死 2,000，先以返回 total 和服务端拒绝为准 |
| `all` 待补证据 | 关键词反查、查流量来源、关联流量、ABA 选品 | 完成非零第二页、自然末页和零结果夹具后开放；来源接口允许 `pager.page=0,size=null`，不得做响应页大小强校验 |
| `page` 或专用流程 | 关键词选品、选市场、关键词对比、拓展流量词、关键词转化率、实时查竞价 | 先保留单页；分页需要冻结 prepare、动态列、任务 ID、SP/SB 合并和聚合口径后再开放 |
| 官方文件/单报告 | 出单词反查、全球商标库、Listing Analysis | 官方 XLSX 原样透传或生成单报告，不循环分页；在结果元数据明确“不适用分页” |

## 通用合同

新增场景分页合同注册表，每项必须声明：

1. 请求传输方式、页码起点、页字段或 offset 字段、页大小字段及筛选冻结字段。
2. rows、total、has-next 的路径和类型；缺失 total 时只能返回 `unverified`，不能当作零或完成。
3. 页面可选大小、已验证访问上限和服务端拒绝特征；未知值保持未知。
4. 行唯一键和重复处理策略。关键词使用站点、周期和规范化关键词；市场使用类目 ID/path；产品使用子 ASIN。
5. 是否允许重试和恢复。`replay_safe=false` 场景不能由通用重试重复创建任务或重复扣费。
6. 导出适配器。流式写入普通行；动态列和辅助汇总先建立有限状态，再提交最终工作簿。

通用分页引擎只复用顺序请求、请求指纹、原子页文件、检查点、总时限、有限重试和进度事件。响应解析、行键、上限和导出全部由场景合同提供。

## 分批开发与门禁

### A 批：普通 JSON

先完成选竞品、关键词挖掘、关键词反查、查流量来源。每个场景至少需要：请求第一页和第二页的脱敏 fixture、唯一键无重叠断言、自然短页、零结果、页大小变化和超限行为。A 批中只有选竞品和关键词挖掘已经具备网页第二页证据；关键词反查和流量来源继续保持 page 模式。

### B 批：固定首页和附加上下文

处理 ABA 选品、关联流量、流量词对比、拓展流量词。先删除或绕过固定首页逻辑，再验证 prepare 和变体只运行一次；动态列、Unique Words、ASIN 辅助表及百分比必须在全范围聚合后导出。任何 manager/export 的 `rows[:100]` 都要在 all 分支单独解除，并保留 page 兼容。

### C 批：HTML

处理关键词选品、选市场。解析各自主结果区域的当前页和总数，区分登录页、空表和结构变化；表单分页必须保留排序和过滤字段。没有可靠 total 时不开放 all。

### D 批：任务和额度

处理关键词转化率和实时查竞价。任务只创建一次，翻页只查询同一 task ID；记录额度、SP/SB 两路页边界、恢复和失败语义。`replay_safe=false` 的场景先只支持 page。

### E 批：官方文件和报告

验证导出文件是完整结果还是选中范围，记录文件内行数和服务端声明；Listing Analysis 固定为单报告能力，不进入分页循环。

## 内存与导出要求

全量任务不得把所有原始响应和格式化副本同时放入内存。分页响应先原子写入任务目录，导出通过行迭代器读取一页；动态辅助数据只保留有界集合或磁盘中间结果。每个合同设置单页字节上限、总超时、页数上限和取消检查。最终结果只返回行数、覆盖状态、警告和有限预览，原始页文件留在任务目录供恢复和审计。

## 发布门禁

场景只有在网页证据、脱敏 fixture、单元测试、导出行数对照、恢复测试和内存基准均通过后，才把 `collection_scope=all` 加入 CLI/MCP 公共参数。未达到门禁的场景继续使用 page，并在 Skill 和场景列表中显示能力状态。
