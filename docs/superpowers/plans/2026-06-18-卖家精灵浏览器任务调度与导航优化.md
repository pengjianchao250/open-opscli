# 卖家精灵浏览器任务调度与导航优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让卖家精灵 browser-route 复用当前页面、按错误类型随机等待，并在登录失效时立即恢复，同时完成默认 Patchright 依赖闭环。

**Architecture:** 保持单账号单 worker 串行队列，在 worker 内增加纯函数错误分类和页面目标判断。主请求仅对会话失效执行一次重新登录重试，其他异常交给队列分类冷却。

**Tech Stack:** Python 3.10+、asyncio、Patchright/Playwright async API、pytest。

- [ ] **Step 3: Implement minimal classification and interval logic**

在 worker 中增加常量和纯函数：

```python
TASK_INTERVAL_RANGE_SECONDS = (1.0, 5.0)
NETWORK_COOLDOWN_RANGE_SECONDS = (3.0, 5.0)
RISK_COOLDOWN_RANGE_SECONDS = (15.0, 20.0)

def _failure_cooldown_seconds(exc: Exception) -> float:
    if _is_session_expired_error(exc) or isinstance(exc, SellerSpriteConfigError):
        return 0.0
    if _is_risk_control_error(exc):
        return random.uniform(*RISK_COOLDOWN_RANGE_SECONDS)
    if _is_transient_network_error(exc):
        return random.uniform(*NETWORK_COOLDOWN_RANGE_SECONDS)
    return 0.0
```

队列捕获异常时只设置分类后的冷却；正常任务间隔使用每次生成的 `random.uniform(1, upper_bound)`，配置默认上限改为 5 秒，显式 `0` 仍关闭等待。
