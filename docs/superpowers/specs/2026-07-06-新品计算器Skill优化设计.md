# 新品计算器 Skill 优化设计

## 目标

在不修改 calculator CLI 和 `v0.0.1` 版本号的前提下，精简 `ops-new-product-calculator` 的主上下文，并补齐已有草稿、结果查询和任务复制流程。

## 已确认方案

采用渐进式拆分：

- `SKILL.md` 保留触发、入口路由、全局门禁和命令速查。
- `references/draft-workflow.md` 保存草稿与字段细节。
- `references/result-workflow.md` 保存任务查询、复制和结果输出细节。
- 测试先建立 RED 基线，再修改 Skill。
- 主 Skill 统一列出创建页、列表页和结果详情页；两个参考文件分别保留所属路由。

## 入口路由

| 用户状态 | 默认路径 |
|---|---|
| 尚无草稿 | 下拉选择 → `draft` → CSV → `validate` → 确认 → `submit` |
| 已有草稿 | `show` → `validate` → 确认 → `submit` |
| 已有任务 | `detail`；信息不足用 `list`；复用任务用 `copy` |

## 不变量

- 不直接调用 Polaris 后端 API。
- 非认证类 `opscli` 失败立即使用 `ops-feedback`。
- 未校验通过或未获得确认不得 `submit`。
- 不泄露 JWT、Cookie、`sudo`。
- 新草稿和复制草稿不得覆盖已有目录。
- `data/VERSION.json` 保持不变。
- Web 路由固定为 `/newProductCalculator`、`/calculatorResultList` 和带 `task_code` / `sudo` 的 `/calculatorDatail`。

## 测试

新增契约测试验证引用文件、入口路由、`show` / `copy`、主文件精简和 JSON 真实校验。执行阶段遵循 RED→GREEN→REFACTOR。
