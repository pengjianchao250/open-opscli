# 卖家精灵浏览器任务调度与导航优化设计

## 背景

当前 browser-route worker 会在每个任务开始时固定访问首页，再访问目标场景页；任务间隔固定为 8 秒，任意失败都会让同账号后续任务冷却 120 秒。该策略增加了无效导航，也把登录、配置、代码、网络和风控错误混为同一种恢复方式。

当前工作区正在把默认浏览器运行时切换为 Patchright。Patchright 官方将 Python API 定位为 Playwright 的兼容替代，因此现有 `page`、`locator`、`route`、`expect_response`、`context.request` 和 persistent context 调用保持不变，只切换 async API import 和启动参数。

## 目标

1. 同账号任务保持串行和浏览器上下文复用。
2. 正常任务间隔改为每次随机 1-5 秒。
3. 网络抖动后随机等待 3-5 秒。
4. HTTP 429、验证码或疑似风控后随机等待 15-20 秒。
5. 登录失效立即重新登录并重试一次，不进入冷却。
6. 配置、账号和代码错误立即失败，不阻塞后续任务。
7. 不再为每个任务固定访问首页，按当前页面和目标场景决定刷新、跳转或登录。
8. 保持 Playwright 回退能力，并使默认 Patchright 配置、依赖和文档一致。

## 页面导航状态机

worker 获取复用页面后，根据当前 URL 和目标 referer 执行以下动作：

| 当前状态 | 动作 |
| --- | --- |
| 新页面、`about:blank`、外站或未知页面 | 直接导航到目标 referer |
| 登录页 | 使用目标 referer 作为 callback 登录 |
| 与目标 referer 同一路径且 URL 完全一致 | 刷新当前页 |
| 与目标 referer 同一场景但查询参数不同 | 导航到新 referer，使页面状态与任务参数一致 |
| 其他卖家精灵场景页 | 导航到目标 referer |
| 导航后被自动重定向到登录页或出现未登录标识 | 登录后重新导航目标 referer 一次 |

首页不再作为通用登录探针。登录状态由最终 URL、页面未登录标识和接口响应共同判断。

## 请求与登录恢复

页面准备和请求触发方式保持现有设计：优先点击页面查询按钮并劫持请求，无法触发时使用浏览器上下文 request API。

主请求返回 `ERR_GLOBAL_SESSION_EXPIRED`、HTTP 401/403 或登录页内容时：

1. 立即使用当前账号重新登录；
2. 回到目标 referer；
3. 重新执行主请求一次；
4. 第二次仍失败则返回原始业务错误，不继续循环重试。

登录恢复不设置冷却，因为等待不会修复失效会话。

## 等待与错误分类

正常任务结束后，下一任务基于单次随机值补足 1-5 秒间隔，而不是固定等待。

失败后只对可恢复的外部错误设置下一任务冷却：

| 错误类型 | 识别依据 | 冷却 |
| --- | --- | --- |
| 登录失效 | `ERR_GLOBAL_SESSION_EXPIRED`、401/403、登录跳转 | 0 秒，立即登录恢复 |
| 网络抖动 | 浏览器 fetch/context request 失败、连接错误、超时、常见临时 5xx | 随机 3-5 秒 |
| 风控 | 429、验证码、rate limit、risk control 等明确标识 | 随机 15-20 秒 |
| 配置、账号、代码错误 | `SellerSpriteConfigError` 或未归类异常 | 0 秒，立即失败 |

随机值在失败发生时生成并记录到 worker 的 `cooldown_until`，队列日志继续输出实际等待秒数。

## Patchright 兼容

保留运行时选择：

- Patchright：`patchright.async_api.async_playwright`，persistent context 使用 `no_viewport=True`。
- Playwright：`playwright.async_api.async_playwright`，保留固定 viewport。

不替换其他 browser API。默认运行时为 Patchright，因此默认卖家精灵依赖必须可安装 Patchright；兼容 extra 和 README/Skill 的安装说明同步更新，避免默认配置启动后才报告缺包。

## 测试范围

1. 正常任务随机间隔边界为 1-5 秒。
2. 网络错误冷却边界为 3-5 秒。
3. 429、验证码和风控错误冷却边界为 15-20 秒。
4. 登录、配置和未知代码错误不冷却。
5. 同目标 URL 刷新，不访问首页。
6. 不同目标场景直接导航，不访问首页。
7. 自动跳转登录后完成一次登录恢复。
8. 主请求会话过期只重试一次。
9. Patchright 与 Playwright loader、persistent context 启动参数都通过单元测试。
10. 卖家精灵与 MCP 相关回归测试通过。

## 非目标

- 不增加多账号并行调度。
- 不改变场景 payload、导出格式或 MCP 参数协议。
- 不通过更多随机鼠标动作伪装真人。
- 不调整异步任务状态文件结构。
