# 卖家精灵模块外部项目调用指南

本文档用于其他项目接入 `opscli` 的卖家精灵模块。当前推荐把 `opscli seller-sprite` 当作外部命令调用，避免新项目直接耦合 `opscli.seller_sprite` 内部代码结构。

## 一、调用方式选择

| 方式 | 推荐度 | 适用场景 | 说明 |
| --- | --- | --- | --- |
| CLI 子进程调用 | 高 | 后端服务、任务执行器、飞书任务触发器 | 最稳定，其他项目只依赖命令和 JSON 输出 |
| MCP Tool 调用 | 高 | AI Agent、MCP Server、自动化助手 | 适合让 Agent 直接调用卖家精灵能力 |
| Python SDK 直接 import | 中 | 与 `opscli` 同环境部署的内部项目 | 方便但耦合内部类，后续重构风险更高 |

## 二、环境准备

调用项目需要确保本机或运行容器中能执行：

```bash
opscli seller-sprite scenarios
```

如果项目直接安装 Python 包，包名为：

```bash
pip install aukeys-opscli
```

本地开发时也可以用 editable 安装：

```bash
pip install -e D:/workspace/open-opscli
```

卖家精灵账号通过环境变量或项目 `.env` 注入。`opscli` 会从当前目录向上查找 `.env`，真实环境变量优先级更高。

单账号配置：

```env
OPSCLI_SELLER_SPRITE_USERNAME=your_username
OPSCLI_SELLER_SPRITE_PASSWORD=your_password
OPSCLI_SELLER_SPRITE_OUTPUT_DIR=D:/data/seller_sprite_runs
OPSCLI_SELLER_SPRITE_PAGE_SIZE=100
OPSCLI_SELLER_SPRITE_TASK_TIMEOUT_SECONDS=600
```

账号池配置：

```env
OPSCLI_SELLER_SPRITE_ACCOUNT_NAME=default
OPSCLI_SELLER_SPRITE_ACCOUNTS=[{"name":"default","username":"user@example.com","password":"secret"}]
OPSCLI_SELLER_SPRITE_OUTPUT_DIR=D:/data/seller_sprite_runs
```

不要把真实账号密码提交到代码仓库。单个本地执行任务默认最多运行 600 秒；超时任务会失败并释放对应工作账号，防止后续队列永久阻塞。部署环境可通过 `OPSCLI_SELLER_SPRITE_TASK_TIMEOUT_SECONDS` 调整该阈值。

## 三、支持场景

| scenario | 名称 | 必填参数 | 常用可选参数 |
| --- | --- | --- | --- |
| `competitor-lookup` | 竞品查询 | 无 | `keyword`、`brand`、`sellerName`、`asins`、`node`、`orderField` |
| `product-research` | 选竞品 | 无 | `keyword`、`includeBrands`、`excludeBrands`、`node`、`sellerTypes` |
| `keyword-miner` | 关键词挖掘 | `keyword` | `filterRootWord`、`amazonChoice`、`includeHighFrequency` |
| `keyword-reverse` | 关键词反查 | `asin` | `includeHighFrequency`、`badges`、`amazonChoice`、`exactly` |

站点参数使用 Amazon 站点代码：

```text
US, UK, DE, FR, JP, CA, IT, ES, IN, MX
```

周期参数：

```text
30d / nearly / latest30 / 2026-03 / 202603
```

## 四、推荐方案：CLI 子进程调用

列出场景：

```bash
opscli seller-sprite scenarios
```

关键词反查：

```bash
opscli seller-sprite run keyword-reverse \
  --site US \
  --period 30d \
  --params "{\"asin\":\"B0XXXXXXX\",\"includeHighFrequency\":true}" \
  --page-size 100 \
  --export-format json
```

关键词挖掘：

```bash
opscli seller-sprite run keyword-miner \
  --site US \
  --period 30d \
  --params "{\"keyword\":\"flashlight\",\"filterRootWord\":1,\"amazonChoice\":true}" \
  --page-size 100 \
  --export-format json
```

竞品查询：

```bash
opscli seller-sprite run competitor-lookup \
  --site DE \
  --period 2026-04 \
  --params "{\"brand\":\"anker\",\"sellerName\":\"AnkerDirect\",\"asins\":\"B00FLYWNYQ\"}" \
  --page-size 100 \
  --export-format xlsx
```

Python 封装示例：

```python
import json
import subprocess
from dataclasses import dataclass
from pathlib import Path
from typing import Any


@dataclass
class SellerSpriteCliClient:
    opscli_bin: str = "opscli"
    output_dir: str | None = None

    def run_scenario(
        self,
        scenario: str,
        *,
        params: dict[str, Any] | None = None,
        site: str = "US",
        period: str = "30d",
        page_size: int = 100,
        export_format: str = "json",
        job_id: str | None = None,
    ) -> dict[str, Any]:
        cmd = [
            self.opscli_bin,
            "seller-sprite",
            "run",
            scenario,
            "--site",
            site,
            "--period",
            period,
            "--params",
            json.dumps(params or {}, ensure_ascii=False),
            "--page-size",
            str(page_size),
            "--export-format",
            export_format,
        ]

        if self.output_dir:
            Path(self.output_dir).mkdir(parents=True, exist_ok=True)
            cmd.extend(["--output-dir", self.output_dir])
        if job_id:
            cmd.extend(["--job-id", job_id])

        completed = subprocess.run(
            cmd,
            capture_output=True,
            text=True,
            encoding="utf-8",
            check=False,
        )
        if completed.returncode != 0:
            raise RuntimeError(
                "opscli seller-sprite 调用失败："
                f"exit={completed.returncode}, stderr={completed.stderr.strip()}"
            )

        return json.loads(completed.stdout)


client = SellerSpriteCliClient(output_dir="D:/data/seller_sprite_runs")
result = client.run_scenario(
    "keyword-reverse",
    site="US",
    period="30d",
    params={"asin": "B0XXXXXXX", "includeHighFrequency": True},
)

print(result["job_id"], result["row_count"], result["export"]["path"])
```

## 五、CLI 返回结构

`opscli seller-sprite run` 成功时直接输出任务结果 JSON，不包 `success` 字段。

核心字段：

```json
{
  "job_id": "seller-sprite-keyword-reverse-20260604-101010-a1b2c3",
  "scenario": "keyword-reverse",
  "site": "US",
  "period": "30d",
  "row_count": 100,
  "root_dir": "D:/data/seller_sprite_runs/seller-sprite-keyword-reverse-...",
  "params_path": ".../params.json",
  "raw_path": ".../raw.json",
  "result_path": ".../result.json",
  "export": {
    "path": ".../seller-sprite-keyword-reverse-....json",
    "filename": "seller-sprite-keyword-reverse-....json",
    "url": "file:///...",
    "format": "json",
    "mime_type": "application/json"
  },
  "data": [],
  "warnings": []
}
```

落盘文件说明：

| 文件 | 说明 |
| --- | --- |
| `params.json` | 本次请求参数和最终接口 payload |
| `raw.json` | 卖家精灵原始响应 |
| `result.json` | 标准化任务结果 |
| `*.json` / `*.xlsx` | 导出文件 |

## 六、MCP 调用方式

如果另一个项目是 AI Agent 或 MCP Client，可以直接调用 MCP tools：

```text
seller_sprite_scenarios
seller_sprite_run
seller_sprite_job_status
seller_sprite_export
```

`seller_sprite_run` 参数示例：

```json
{
  "scenario": "keyword-reverse",
  "site": "US",
  "period": "30d",
  "params": {
    "asin": "B0XXXXXXX",
    "includeHighFrequency": true
  },
  "page_size": 100,
  "export_format": "json",
  "output_dir": "D:/data/seller_sprite_runs"
}
```

MCP 返回结构统一为：

```json
{
  "success": true,
  "data": {},
  "error": null
}
```

失败时会返回：

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "SellerSpriteConfigError",
    "message": "缺少 OPSCLI_SELLER_SPRITE_USERNAME"
  }
}
```

## 七、Python SDK 直接调用

仅建议在内部项目与 `opscli` 同环境部署时使用。

```python
import asyncio

from opscli.seller_sprite.domain.models import SellerSpriteScenarioRequest
from opscli.seller_sprite.services import SellerSpriteApiManager


async def run() -> dict:
    request = SellerSpriteScenarioRequest(
        scenario="keyword-reverse",
        site="US",
        period="30d",
        params={"asin": "B0XXXXXXX", "includeHighFrequency": True},
        page_size=100,
        output_dir="D:/data/seller_sprite_runs",
        export_format="json",
    )
    result = await SellerSpriteApiManager().run(request)
    return result.to_dict()


payload = asyncio.run(run())
```

读取已落盘任务：

```python
from opscli.seller_sprite.services import SellerSpriteApiManager

status = SellerSpriteApiManager().job_status("seller-sprite-keyword-reverse-xxx")
```

## 八、外部项目推荐封装

建议外部项目只定义一个很薄的 adapter：

```text
your_project/
  integrations/
    seller_sprite_client.py
```

对业务层暴露：

```python
client.run_keyword_reverse(asin="B0XXXXXXX", site="US")
client.run_keyword_miner(keyword="flashlight", site="US")
client.run_competitor_lookup(brand="anker", site="DE")
```

内部再映射到 `opscli seller-sprite run`。这样后续即使 `opscli` 内部从 CLI 切到 MCP 或 SDK，业务层也不用改。

## 九、注意事项

1. 优先使用新版 `opscli.seller_sprite`，不要接入 `opscli.seller_sprite_legacy`。
2. CLI 成功输出是任务结果 JSON，不是 `{success, data, error}` 包装结构。
3. MCP 成功输出才是 `{success, data, error}` 包装结构。
4. `keyword-miner` 必须传 `keyword`。
5. `keyword-reverse` 必须传 `asin`。
6. `includeHighFrequency=true` 时会额外请求高频词接口；失败会写入 `warnings`，主表继续导出。
7. 账号密码只通过环境变量、`.env` 或部署平台 secret 注入。
8. 外部项目应保存 `job_id`、`result_path` 和 `export.path`，便于后续报告分析和任务追踪。
