# opscli 从零安装部署指南

> 本文档面向 AI Agent（如 OpenClaw）自动执行，步骤顺序严格，每步均含验证命令，失败时有明确排查提示。

---

## 前置条件

### Python 版本检查

```bash
python3 --version
```

**要求**：Python >= 3.10。若版本不满足，需先升级 Python。

---

## 安装 opscli

```bash
pip install aukeys-opscli
```

**验证安装**：

```bash
opscli --version
# 预期输出：opscli v0.0.4

opscli --help
# 预期输出包含：auth, query, skills 子命令
```

---

## 登录认证

安装完成后，需要先登录才能使用认证和查询功能：

```bash
opscli auth login
# 将自动打开浏览器，完成 OAuth2 Device Flow 授权（300 秒内完成）
```

**登录流程**：
1. 终端显示验证码，自动打开浏览器
2. 在浏览器确认授权（需已登录运营系统前台）
3. 授权成功后自动保存凭证并同步系统列表

**验证登录状态**：

```bash
opscli auth token status
# 预期：显示 ops 和 polaris 两个系统的 Token 状态（均为"有效"）
```

## 安装 Skills（登录后执行）

> Skills 是 AI Agent 工具包，安装后可在 OpenClaw / Claude Code 等 AI 工具中直接调用。
> **`ops-dataset-query` 的远端数据升级需要已登录 ops 系统，必须在登录后执行。**

### 内置 Skill 说明

| Skill 名称 | 功能 | 支持远端升级 |
|-----------|------|------------|
| `ops-auth` | 认证授权管理（登录、Token 查看与刷新、系统管理） | 否 |
| `ops-dataset-query` | 数据集字段索引与查询转发 | 是（需已登录） |
| `ops-skills` | Skill 生命周期管理（安装/列表/升级） | 否 |

### 第一步：安装全部内置 Skills

#### 方式 A：交互式安装（推荐，自动检测运行时）

```bash
opscli skills install
# 进入 TUI 界面，勾选所有 Skill 后确认，自动检测并安装到当前 AI 工具目录
```

#### 方式 B：非交互式安装（适合脚本/CI）

指定运行时，跳过交互界面：

```bash
# 安装到 OpenClaw
opscli skills install ops-auth --runtime openclaw
opscli skills install ops-dataset-query --runtime openclaw
opscli skills install ops-skills --runtime openclaw

# 安装到 Claude Code
opscli skills install ops-auth --runtime claude
opscli skills install ops-dataset-query --runtime claude
opscli skills install ops-skills --runtime claude

# 同时安装到所有已检测的运行时
opscli skills install ops-auth --runtime all
opscli skills install ops-dataset-query --runtime all
opscli skills install ops-skills --runtime all
```

安装后目录结构（以 OpenClaw 为例）：

```
~/.openclaw/skills/
├── ops-auth/
│   ├── data/VERSION.json
│   └── SKILL.md
├── ops-dataset-query/
│   ├── data/VERSION.json
│   ├── data/datasets.csv
│   ├── data/dataset_fields.csv
│   ├── data/query_metadata.json
│   ├── scripts/
│   └── SKILL.md
└── ops-skills/
    ├── data/VERSION.json
    └── SKILL.md
```

**验证安装结果**：

```bash
opscli skills list --pretty
# 预期：列出所有已安装 Skill，包含 name、version、path、runtime 字段
```

### 第二步：升级 ops-dataset-query 远端数据

`ops-dataset-query` 的字段索引数据存储于远端，安装后需执行一次升级拉取最新数据：

```bash
opscli skills upgrade ops-dataset-query
# 预期输出：{"status": "upgraded", "from_version": "...", "to_version": "..."}
# 若已是最新：{"status": "skipped", "reason": "already at latest version ..."}
```

**验证升级结果**：

```bash
opscli skills status --pretty
# 预期：ops-dataset-query 的 needs_upgrade 为 false
```

## 完整安装流程（一键版）

### 阶段一：安装 opscli

```bash
pip install aukeys-opscli && opscli --version
```

预期输出：`opscli v0.0.4`

### 阶段二：登录（需人工完成浏览器授权）

```bash
opscli auth login
# 在浏览器完成授权后继续执行：
opscli auth token status
```

### 阶段三：安装并升级 Skills

```bash
# 将 --runtime openclaw 替换为实际使用的 AI 工具名
# 可选值：openclaw / claude / codex / opencode / all
opscli skills install ops-auth --runtime openclaw --force && \
opscli skills install ops-dataset-query --runtime openclaw --force && \
opscli skills install ops-skills --runtime openclaw --force && \
opscli skills upgrade ops-dataset-query && \
opscli skills list --pretty
```

## 故障排查

### 问题 1：`opscli` 命令找不到

```bash
# 检查 pip 安装路径是否在 PATH 中
which opscli

# 若不存在，尝试重新安装
pip install --force-reinstall aukeys-opscli

# 或确认 pip 安装目录已加入 PATH
python3 -m site --user-base
# 将输出路径下的 bin/ 加入 PATH
```

### 问题 2：安装时依赖冲突

```bash
# 在隔离环境中安装
python3 -m venv ~/.venv-opscli
source ~/.venv-opscli/bin/activate
pip install aukeys-opscli
```

### 问题 3：Skills 安装时提示"未检测到运行时"

```bash
# 手动创建目录后重试
mkdir -p ~/.openclaw/skills/
opscli skills install ops-auth --runtime openclaw

# 或直接指定目录
opscli skills install ops-auth --skills-dir ~/.openclaw/skills/
```

### 问题 4：Skills 安装提示"已存在"

```bash
# 添加 --force 覆盖安装
opscli skills install ops-auth --runtime openclaw --force
```

### 问题 5：`skills upgrade` 失败（Token 过期或网络异常）

```bash
# 刷新 Token 后重试
opscli auth token refresh --all
opscli skills upgrade ops-dataset-query

# 检查网络连通性
opscli auth doctor
```

### 问题 6：登录超时（Device Flow 300 秒内未完成）

```bash
# 重新发起登录
opscli auth login
```
