## 安装

```bash
# 开发模式安装（推荐开发时使用，代码改动即时生效）
cd /path/to/opscli
pip install -e .

# 验证安装
opscli --version
```

### 依赖要求

- Python >= 3.10
- 自动安装的依赖：typer, httpx, cryptography, rich, keyring

---

## 快速开始

```bash
# 1. 登录（自动打开浏览器，完成授权）
opscli auth login

# 2. 查看登录状态
opscli auth token status

# 3. 获取 ops 运营系统 JWT
opscli auth token get --system ops

# 4. 获取 polaris 刊登系统 JWT
opscli auth token get --system polaris

# 5. 退出登录
opscli auth logout
```

## CLI 命令参考

### 登录与登出

#### `opscli auth login`

发起 Device Flow 授权，自动打开浏览器完成登录。

```bash
opscli auth login
```

**流程说明：**

1. CLI 向后端申请设备码，终端显示验证码
2. 自动打开浏览器访问授权页面
3. 用户在浏览器确认授权（需已登录前台系统）
4. CLI 轮询授权结果，成功后保存凭证到本地

**输出示例：**

```
请在浏览器打开： http://localhost/cli-auth
输入验证码：   BQK1-OSVF
等待授权中...（300 秒内完成）

✓ 授权成功！账号：user@example.com
```

#### `opscli auth logout`

清除本地所有凭证（包括 session 和所有系统 JWT）。

```bash
opscli auth logout
```

#### `opscli auth token status`

查看当前登录状态与各系统 Token 情况。

```bash
opscli auth token status
```

**输出示例：**


### Token 管理

#### `opscli auth token get`

获取指定系统的 JWT（纯文本输出，适合脚本管道使用）。

```bash
opscli auth token get --system <别名>
opscli auth token get -s <别名>
```

| 参数 | 说明 |
|------|------|
| `--system`, `-s` | 系统别名（`ops` 或 `polaris`） |

**示例：**

```bash
# 获取 ops 系统 JWT
opscli auth token get --system ops

# 获取 polaris 系统 JWT
opscli auth token get -s polaris

# 在脚本中使用
TOKEN=$(opscli auth token get -s ops)
curl -H "Authorization: Bearer $TOKEN" http://ops.cm/api/v1/some-resource
```

#### `opscli auth token check`

检测指定系统 JWT 是否有效。

```bash
opscli auth token check --system <别名>
opscli auth token check -s <别名>
```

**输出示例：**

```
✓ 有效  剩余 6800 秒
```

#### `opscli auth token refresh`

刷新 JWT。支持刷新单个系统或全部系统。

```bash
# 刷新单个系统
opscli auth token refresh --system ops
opscli auth token refresh -s polaris

# 刷新全部系统
opscli auth token refresh --all
```

### 系统管理

#### `opscli auth system list`

列出所有已注册的系统（内置 + 手动添加 + ops 同步）。

```bash
opscli auth system list
```

**输出示例：**

```
┃ 别名    ┃ System Key   ┃ URL              ┃ 来源    ┃

└─────────┴──────────────┴──────────────────┴─────────┘
```

#### `opscli auth system sync`

从 ops 服务端同步多实例系统列表（需先登录）。

```bash
opscli auth system sync
```

#### `opscli auth system add`

手动添加系统实例。

```bash
opscli auth system add --alias <别名> --url <地址> [--key <存储键>]
```

| 参数 | 说明 |
|------|------|
| `--alias` | 系统别名（必填） |
| `--url` | 系统地址（必填） |
| `--key` | 存储键，默认由 alias 自动生成 |

**示例：**

```bash
opscli auth system add --alias 数据分析 --url http://analytics.cm
```

#### `opscli auth system remove`

移除手动添加的系统（内置系统不可移除）。

```bash
opscli auth system remove --alias <别名>
```

## Skills 管理

`skills` 模块用于管理本地 Skill 生命周期，当前内置支持 `dataset-fields`。

### `opscli skills list`

列出当前扫描到的 Skill。

```bash
opscli skills list
opscli skills list --pretty
opscli skills list --skills-dir ~/.claude/skills
```

### `opscli skills install`

安装内置模板到本地。

```bash
opscli skills install dataset-fields
opscli skills install dataset-fields --skills-dir ~/.claude/skills
opscli skills install dataset-fields --skills-dir ~/.claude/skills --force
```

### `opscli skills status`

查看本地安装状态，并检查远端版本。

```bash
opscli skills status
opscli skills status --pretty
```

返回结果重点字段：

| 字段 | 说明 |
|------|------|
| `installed` | 本地已安装 Skill 列表 |
| `remote_manifest` | 远端 manifest 数据 |
| `remote_summary` | 远端调试摘要，含 `ops_url` 和 manifest 地址 |
| `remote_error` | 远端错误信息 |

### `opscli skills upgrade`

拉取远端最新的 `dataset-fields` 元数据文件。

```bash
opscli skills upgrade
opscli skills upgrade dataset-fields
opscli skills upgrade dataset-fields --force
opscli skills upgrade dataset-fields --pretty
```

### `dataset-fields` 本地脚本

安装后可以直接在 Skill 目录里运行：

```bash
python .claude/skills/dataset-fields/scripts/search.py "订单成本"
python .claude/skills/dataset-fields/scripts/search.py "cost" --dataset sales_order_d -n 5

python .claude/skills/dataset-fields/scripts/updater.py --check
python .claude/skills/dataset-fields/scripts/updater.py --force --pretty

python .claude/skills/dataset-fields/scripts/query.py build --dataset ds_e93be345cfa1 --dimension date_id --output /tmp/query.json
python .claude/skills/dataset-fields/scripts/query.py build --dataset ds_e93be345cfa1 --dimension country_name:f_dim001 --metric price:sum:f_metric001 --where 'country_name|in|["美国"]' --where 'date_id|between|["2022-01-01","2022-03-31"]' --order-by f_metric001:desc --output /tmp/query.json
python .claude/skills/dataset-fields/scripts/query.py build --dataset ds_e93be345cfa1 --dimension date_id --run --pretty
python .claude/skills/dataset-fields/scripts/query.py metadata --dataset ds_e93be345cfa1
python .claude/skills/dataset-fields/scripts/query.py run --payload /tmp/query.json
```

说明：

- `search.py` 只做本地字段检索
- `query.py` 不直连后端，只会转调 `opscli query`
- 所有查询执行统一经过 `opscli`

### `skills` 推荐联调步骤

```bash
opscli auth login
opscli skills install dataset-fields
opscli skills status --pretty
opscli skills upgrade dataset-fields --pretty
python .claude/skills/dataset-fields/scripts/search.py "GMV" -n 5
```

## Python SDK 调用

其他 Python 项目可以通过 `AuthClient` 类直接调用，无需执行 CLI 命令。

### 安装依赖

```python
# pyproject.toml 中添加依赖
[project]
dependencies = [
    "opscli",
]
```

或开发模式：

```bash
pip install -e /path/to/opscli
```

### API 参考

```python
from opscli import AuthClient

client = AuthClient()
# 可选参数 base_dir 指定凭证存储目录，默认 ~/.config/opscli/
```

#### 方法列表

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `is_authenticated()` | `bool` | 是否已登录（session 存在且未过期） |
| `get_token(alias)` | `str` | 获取指定系统 JWT（自动缓存+刷新） |
| `check_token(alias)` | `dict` | 检测 token 有效性，返回 `{"valid": bool, "expires_in": int}` |
| `refresh_token(alias)` | `str` | 强制刷新指定系统 JWT |

### 使用示例

#### 基础用法

```python
from opscli import AuthClient

client = AuthClient()

# 检查登录状态
if not client.is_authenticated():
    print("未登录，请先执行: opscli auth login")
    exit(1)

# 获取 JWT
ops_token = client.get_token("ops")
polaris_token = client.get_token("polaris")
```

#### 调用业务 API

```python
import httpx
from opscli import AuthClient

client = AuthClient()

# 获取 ops 系统 token 并调用 API
token = client.get_token("ops")
resp = httpx.get(
    "http://ops.cm/api/v1/operation-reminder/list",
    headers={"Authorization": f"Bearer {token}"},
)
print(resp.json())

# 获取 polaris 系统 token 并调用 API
token = client.get_token("polaris")
resp = httpx.get(
    "http://po2.cm/api/some-endpoint",
    headers={"Authorization": f"Bearer {token}"},
)
print(resp.json())
```

#### 异常处理

```python
from opscli import AuthClient
from opscli.auth.exceptions import (
    NotAuthenticatedError,
    TokenFetchError,
    SystemNotFoundError,
)

client = AuthClient()

try:
    token = client.get_token("ops")
except NotAuthenticatedError:
    print("未登录或登录已过期，请运行: opscli auth login")
except SystemNotFoundError:
    print("系统别名不存在，请检查别名是否正确")
except TokenFetchError as e:
    print(f"获取 JWT 失败: {e}")
```

#### 检测 Token 状态

```python
from opscli import AuthClient

client = AuthClient()

result = client.check_token("ops")
if result["valid"]:
    print(f"Token 有效，剩余 {result['expires_in']} 秒")
else:
    # 自动刷新
    token = client.refresh_token("ops")
```

#### 统一认证参数构造

```python
from opscli import AuthClient

client = AuthClient()

# 业务接口：Bearer JWT + 认证 Cookie
headers, cookies = client.build_request_auth("ops")

# 结果示例：
# headers = {"Authorization": "Bearer <jwt>"}
# cookies = {
#     "polarisUserToken": "<session_id>",
#     "opscliDeviceCode": "<device_code>",  # 本地存在时自动附带
# }

# ops session 型接口：X-Session-Id
session_headers = client.build_session_headers("ops")
```

## 脚本集成示例

### Shell 脚本

```bash
#!/bin/bash
# 自动获取 token 并调用 API

TOKEN=$(opscli auth token get -s ops 2>/dev/null)

if [ $? -ne 0 ]; then
    echo "获取 token 失败，请先登录: opscli auth login"
    exit 1
fi

curl -s -H "Authorization: Bearer $TOKEN" \
    "http://ops.cm/api/v1/operation-reminder/list" | python3 -m json.tool
```

### crontab 定时任务

```cron
# 每天早上 9 点获取 polaris 系统数据
0 9 * * * /usr/local/bin/opscli auth token get -s polaris > /tmp/polaris_token.txt && /path/to/script.sh
```

### Python 定时任务

```python
import httpx
from opscli import AuthClient

client = AuthClient()

def fetch_ops_data(endpoint: str) -> dict:
    """封装带认证的 API 调用"""
    headers, cookies = client.build_request_auth("ops")
    resp = httpx.get(
        f"http://ops.cm{endpoint}",
        headers=headers,
        cookies=cookies,
        timeout=30,
    )
    resp.raise_for_status()
    return resp.json()
```

## 凭证存储说明

### 存储位置

```
~/.config/opscli/
├── credentials.bin    # 加密的凭证文件（session + device_code + JWT）
├── .key               # AES 加密密钥
└── systems.json       # 用户自定义系统列表
```

凭证结构示例：

```json
{
  "session_id": "uuid-1234",
  "device_code": "dc-abc",
  "email": "user@example.com",
  "session_expires_at": "2026-04-23T10:00:00+00:00",
  "tokens": {
    "ops": {
      "jwt": "eyJ...",
      "expires_at": "2026-04-22T12:00:00+00:00",
      "saved_at": 1234567890
    }
  }
}
```

### 安全机制

- 凭证使用 AES-256-GCM 加密存储
- 密钥文件权限为 `600`（仅当前用户可读写）
- 凭证文件权限为 `600`

### 数据结构

credentials.bin 解密后的 JSON 结构：

```json
{
    "session_id": "6abc6ffe85b6...",
    "email": "user@example.com",
    "session_expires_at": "2026-05-18 01:05:25",
    "tokens": {
        "ops": {
            "jwt": "eyJhbGciOi...",
            "expires_at": "2026-04-18T03:05:25+00:00",
            "saved_at": 1744927325
        },
        "polaris": {
            "jwt": "eyJhbGciOi...",
            "expires_at": "2026-04-18T02:05:25+00:00",
            "saved_at": 1744927325
        }
    }
}
```

### Token 生命周期

```
登录 (login)
  └→ 保存 session_id（有效期 30 天）
      └→ 首次 get_token 时自动向后端换取 JWT（有效期约 2 小时）
          └→ JWT 过期前 5 分钟自动刷新
              └→ session 过期后需重新 login
```

## 异常处理

### 异常类层次

```
AuthError                          # 基础认证异常
├── NotAuthenticatedError          # 未登录或 session 已失效
├── SessionExpiredError            # session_id 已过期
├── TokenFetchError                # 从业务系统获取 JWT 失败
├── SystemNotFoundError            # 系统别名未注册
└── DeviceFlowError                # Device Flow 授权流程异常
    ├── DeviceFlowExpiredError     # 设备码已超时
    └── DeviceFlowDeniedError      # 用户拒绝授权
```

### 典型异常场景

| 场景 | 异常 | 处理方式 |
|------|------|----------|
| 未执行过 login | `NotAuthenticatedError` | 引导用户执行 `opscli auth login` |
| session 超过 30 天 | `NotAuthenticatedError` | 重新登录 |
| 系统别名写错 | `SystemNotFoundError` | 检查别名，用 `system list` 查看 |
| 目标系统不可达 | `TokenFetchError` | 检查网络，用 `doctor` 诊断 |
| 浏览器授权超时 | `DeviceFlowExpiredError` | 重新执行 `login` |
| 用户拒绝授权 | `DeviceFlowDeniedError` | 重新执行 `login` |

## 常见问题

### Q: 提示 `No module named 'opscli'`

安装包或设置 PYTHONPATH：

```bash
cd /path/to/opscli
pip install -e .
```

### Q: 登录后浏览器授权页面提示"未检测到登录会话"

需要先在前台系统（http://localhost:3000）登录，确保浏览器有 `polarisUserToken` cookie。

### Q: Token 获取失败

1. 检查登录状态：`opscli auth token status`
2. 检查网络连通性：`opscli auth doctor`
3. 尝试强制刷新：`opscli auth token refresh -s ops`

### Q: `opscli skills status` 提示远端 404

通常表示当前 `ops_url` 指向的环境还没有部署 Skill 相关接口。检查：

1. `~/.config/opscli/config.ini` 中的 `ops_url`
2. 对应环境是否已部署：
   - `/api/v1/data-metrics/datasets/skill/manifest`
   - `/api/v1/data-metrics/datasets/skill/export`
   - `/api/v1/data-metrics/datasets/skill/export-datasets`
   - `/api/v1/data-metrics/datasets/query-metadata`

### Q: `opscli skills upgrade` 提示未登录 ops

先执行：

```bash
opscli auth login
```

然后再重试：

```bash
opscli skills upgrade dataset-fields --pretty
```

### Q: `dataset-fields` 搜索没有结果

依次检查：

1. 是否已安装模板：`opscli skills list`
2. 是否已拉取真实数据：`opscli skills upgrade dataset-fields`
3. 是否指定了错误的 `dataset_alias`
4. 尝试减少过滤条件或扩大关键词范围

### Q: 如何在其他机器上使用

1. 安装包：`pip install opscli`
2. 执行登录：`opscli auth login`
3. 正常使用

### Q: session 多久过期

默认 30 天。每次在浏览器完成 CLI 授权确认时会自动续期 30 天。
