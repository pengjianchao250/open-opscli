# 卖家精灵「关联流量」场景参数调研

> 调研日期：2026-07-23
>
> 场景标识：`association-traffic`
>
> 官方页面：<https://www.sellersprite.com/v3/relation-keyword>

## 1. 结论

关联流量是独立于关键词反查和流量来源的 ASIN 场景。用户输入 1—20 个父体或子体 ASIN，点击“立即查询”后必须选择“用全部变体查询”，MCP 内部固定传 `queryVariations=true`。主接口返回 `data.pagerDto` 分页元数据，本次 5 个 ASIN 的实测总数为 375；正式 MCP 只取第一页 100 条即完成任务。

本地 XLSX 对齐官方 56 列业务主表、表头样式、列宽、数值格式和超链接，只生成业务主表，不生成官方文件中的 `Notes` 页。

## 2. 页面输入与交互

页面输入规则：

- 可输入父体或子体 ASIN；
- 最少 1 个，最多 20 个；
- 单个 ASIN 可按回车加入；
- 支持从 TXT 或 Excel 按单列复制粘贴；
- 适配层接受数组、逗号、空白、换行、制表符及中英文分号分隔文本；
- 适配层去重并统一转为大写，每个 ASIN 校验为 10 位字母数字。

页面流程：

```text
选择站点
  ↓
录入 1—20 个 ASIN
  ↓
点击“立即查询”
  ↓
出现“选择关联流量查询方式”弹窗
  ↓
点击“用全部变体查询”
```

本次页面弹窗显示：

- 全部变体关联流量数：375；
- 当前变体关联流量数：0。

这两个数字是样本动态结果，不是固定参数。

## 3. 页面路由

选择全部变体后，页面路由包含以下字段：

| 字段 | 本次值 | 说明 |
| --- | --- | --- |
| `market` | `1` | 美国站 |
| `pageNum` | `1` | 固定从第一页开始 |
| `pageSize` | `100` | MCP 与其他普通场景统一的每页数量 |
| `desc` | `true` | 默认倒序 |
| `orderField` | `createdTime` | 默认按引流时间排序 |
| `relations` | `[]` | 空数组表示全部关联类型 |
| `queryVariations` | `true` | 固定使用全部变体 |
| `asinList` | JSON 数组 | 输入 ASIN 列表 |

## 4. 接口契约

### 4.1 查询准备

```http
POST /v3/api/relation/traffic/prepare
```

请求核心字段：

```json
{
  "station": "US",
  "asinList": ["B098T9ZFB5"]
}
```

本次响应显示当前变体结果为 0、全部变体结果为 375。

### 4.2 变体统计

```http
POST /v3/api/relation/traffic/variations/stat
```

请求核心字段：

```json
{
  "station": "US",
  "asinList": ["B098T9ZFB5"],
  "queryVariations": true
}
```

该接口用于选择全部变体后的变体展开和关联统计。

### 4.3 主查询

```http
POST /v3/api/relation/traffic
```

完整公共请求形状：

```json
{
  "market": 1,
  "pageNum": 1,
  "pageSize": 100,
  "desc": true,
  "orderField": "createdTime",
  "relations": [],
  "queryVariations": true,
  "asinList": [
    "B098T9ZFB5",
    "B09JW5FNVX",
    "B0B71DH45N",
    "B07MHHM31K",
    "B08RYQR1CJ"
  ]
}
```

结果行路径为 `data.pagerDto.items`，分页字段为：

- `data.pagerDto.page`
- `data.pagerDto.size`
- `data.pagerDto.total`
- `data.pagerDto.took`

2026-07-23 的原始游客样本使用 `pageSize=50`，接口仍把结果限制为 20 条，因此存档中的请求值保持原样。正式 MCP 运行统一使用 `pageNum=1/pageSize=100`；检测到 `pagerDto.size=20` 且仅返回 20 条时，会在 browser worker 内恢复有效登录态并重试一次，成功取得第一页后立即完成，不请求后续页。

browser-route 的查询不能只打开带 query 参数的页面或静默请求主接口。它必须完成可见页面交互：清除旧输入、逐个填写 ASIN 并按回车、核对“已录入 N/20 个 ASIN”、点击“立即查询”，最后在弹窗点击“用全部变体查询”。捕获第一页响应后即结束任务。
