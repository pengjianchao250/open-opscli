# 跨境电商数据能力地图文档集

本目录集中维护从选品到运营优化的数据需求地图、平台数据来源、当前接入能力和候选平台调研。新增平台或调整场景覆盖时，应先更新总地图，再同步对应平台文档。

## 建议阅读顺序

1. [领导汇报版：数据能力现状与资源需求](./领导汇报版-数据能力现状与资源需求.md)：快速了解现状、缺口、账号采购和内部协同需求。
2. [跨境电商全链路数据能力地图](./跨境电商全链路数据能力地图.md)：全链路场景、现有覆盖、缺口和建设优先级。
3. [电商运营数据需求与平台来源地图](./电商运营数据需求与平台来源地图.md)：逐项说明需要什么数据，以及从什么平台、系统或接口取得。
4. [官方平台数据来源核对](./官方平台数据来源核对.md)：官方数据源、授权范围和事实边界。

## 维护约定

- 明确区分“平台具备”“代码已实现”“正式入口已开放”“真实场景已验收”。
- 第三方销量、流量和广告数据标记为估算或代理，不替代第一方经营事实。
- 卖家精灵浏览器插件评论仅供客户端或人工辅助，不进入服务端采集、入库、调度、建模或 VOC 分析。
- 平台文档新增或删除能力后，同步更新两份总地图中的覆盖矩阵和优先级。
