## 一、现有数据能力边界与缺口分析

### 1.1 现有数据集擅长什么

基于 `datasets.csv` 与 `dataset_fields.csv`，当前已覆盖：

| 维度 | 覆盖情况 | 代表字段 |
|------|----------|----------|
| 内部销售财务 | ✅ 完整 | `price`, `gross_profit`, `refund`, `fee` |
| 广告效率 | ✅ 完整 | `acos`, `roas`, `cpc`, `conversions` |
| 库存周转 | ✅ 完整 | `inventory_turnaround_days`, `fba_qty` |
| 流量转化 | ⚠️ 基础 | `sessions`, `convert_percent`, `page_views` |
| 组织归属 | ✅ 完整 | `team_name`, `dev_team_name`, `dept_name` |

### 1.2 关键数据缺口（必须外部补充）

| 缺口维度 | 为什么重要？ | 现有数据无法回答 |
|----------|-------------|-----------------|
| **竞品对标** | 不知道自己在市场中的位置 | "我的价格有没有竞争力？" |
| **关键词排名** | 自然流量来源不明 | "哪些词带来了自然订单？" |
| **Review 深度** | 只知晓星级，不知晓原因 | "客户为什么不满意？" |
| **类目趋势** | 不知道市场是否在增长 | "这个类目还能做多久？" |
| **Buy Box 占有率** | 不知道跟卖影响 | "为什么有流量没转化？" |
| **市场饱和度** | 不知道竞争格局 | "新进入者有多少？利润被压缩了吗？" |

## 三、五维分析模型（内外数据融合）

### 维度一：市场定位分析（Where am I?）

**内部数据 + 外部数据融合：**

| 分析项 | 内部数据 | 外部补充数据 | 融合结论 |
|--------|----------|-------------|----------|
| 市场规模 | 自身销售额 `price` | 类目 Top100 总销量估算（H10） | 我的市场份额 = 我的销量 / 类目总销量 |
| 增长趋势 | 自身销售额环比 | 类目整体搜索量趋势（Google Trends） | 是我在增长还是市场在增长？ |
| 竞争格局 | — | Top10 卖家销量占比、新进入者数量 | 类目是否被垄断？还有机会吗？ |
| 价格带分布 | 自身平均价 `avg_price_cny` | 竞品价格分布（Keepa） | 我处于什么价格带？高端/中端/低端？ |

**运营结论示例：**

> "Kitchen 类目整体搜索量年增 25%，但 Top3 卖家占据 60% 份额。我的产品定价 $29.99 处于中段价格带，上方有 $49.99 高端产品，下方有 $19.99 性价比产品。建议通过差异化（增加配件包）向 $39.99 迁移，避开低价红海。"

---

### 维度二：流量结构分析（Where does traffic come from?）

**现有数据集的问题：** 只能看到总 `sessions` 和自然/广告占比，看不到 **关键词级** 的流量来源。

| 分析项 | 内部数据 | 外部补充数据 | 融合结论 |
|--------|----------|-------------|----------|
| 自然搜索词 | — | ABA 搜索词报告：哪些词带来点击 | 我的 Top10 流量词是什么？ |
| 关键词排名 | — | 爬虫监控：核心关键词的搜索排名位置 | 我在第几页？（第 1 页 vs 第 3 页差异巨大） |
| 广告 vs 自然占比 | `ads_sales_cny` / `price` | — | 广告依赖度 = 广告销售额 / 总销售额 |
| 长尾词机会 | — | 竞品流量词反查（H10 Cerebro） | 竞品有哪些高转化词我没投？ |

**运营结论示例：**

> "60% 的销售额来自 3 个核心大词（竞争激烈，CPC $2.5）。但通过竞品反查发现，有 15 个长尾词（如 'collapsible water bottle for kids'）每月带来 500+ 搜索量，CPC 仅 $0.8，目前无人投。建议立即开设长尾词广告组，预计可降低 ACOS 5-8 个百分点。"

### 维度三：转化效率分析（Why don't they buy?）

**现有数据：** `convert_percent`（转化率）、`page_views`（浏览量）

**缺少：** 为什么跳失？页面哪里有问题？

| 分析项 | 内部数据 | 外部补充数据 | 融合结论 |
|--------|----------|-------------|----------|
| 页面质量 | `rating`, `reviews_qty`（基础） | 爬虫：主图质量、视频数量、A+ 完成度 | 页面丰富度评分 |
| 评价健康度 | — | Review 内容 NLP 分析：差评关键词云 | 客户核心痛点是什么？ |
| QA 覆盖度 | — | 爬虫：QA 数量及问题类型 | 客户在购买前关心什么？ |
| 竞品页面差距 | — | 对标 Best Seller 的页面元素 | 我和 Best Seller 差了什么？ |
| Buy Box 占有率 | — | Keepa：购物车占有率历史 | 是否有跟卖抢 Buy Box？ |

**Review NLP 分析框架：**

```
好评关键词（保持）      差评关键词（紧急修复）
├── easy to use       ├── broke after 1 week
├── great quality     ├── smaller than expected
├── fast shipping     ├── leaking
└── good value        └── bad customer service
```

**运营结论示例：**

> "转化率 8%，低于类目均值 12%。Review NLP 分析显示，23% 的差评提到 'smaller than expected'（比预期小）。检查发现主图未放尺寸对比参照物。同时 QA 中只有 3 个问题（Best Seller 有 15+）。建议：① 主图增加实物与手机对比 ② 补充 10 个 QA 覆盖尺寸/材质问题，预计转化率可提升至 11%。"

### 维度四：广告效率进阶分析（How to optimize ads?）

**现有数据已经很好（ACOS、ROAS、CPC），但缺少：**

| 分析项 | 内部数据 | 外部补充数据 | 融合结论 |
|--------|----------|-------------|----------|
| 关键词排名联动 | `ads_acos` | 广告位与自然位的关联分析 | 广告是否帮助了自然排名提升？ |
| 竞品广告策略 | — | 竞品赞助广告位监控（爬虫） | 竞品在打哪些词？预算规模？ |
| 广告时段效果 | `date_id` | SP-API 小时级广告报告 | 什么时段转化最好？ |
| 品牌新客获取 | `new_to_brand_purchases` | — | 广告是在收割老客还是获取新客？ |

**运营结论示例：**

> "SP 广告 ACOS 22%，但发现投放的 'water bottle' 大词广告位在第 1 页顶部时，自然排名从第 3 页提升到第 1 页；当降低竞价后，自然排名同步下降。说明该词广告对自然排名有**杠杆效应**。建议即使 ACOS 30% 也要维持该词预算，因为自然订单的利润率远高于广告订单。"

---

### 维度五：库存与供应策略（When to restock?）

**现有数据已经很完善，但可以叠加外部数据做预测：**

| 分析项 | 内部数据 | 外部补充数据 | 融合结论 |
|--------|----------|-------------|----------|
| 需求预测 | `average_daily_sales_volume` | Google Trends 季节性曲线 | 旺季需求是上月的几倍？ |
| 竞品库存状态 | — | 爬虫监控竞品库存（Add to Cart 999 法） | 竞品是否断货？（窗口期） |
| 物流时效 | — | 船公司 API / 货代数据 | 海运当前延误多久？ |
| 采购成本趋势 | `purchase_cost` | 原材料期货/供应商报价趋势 | 下个月采购成本会涨吗？ |

**运营结论示例：**

> "基于 Google Trends，'water bottle' 搜索量每年 5 月开始上升，7 月达峰（比均值高 180%）。当前库存周转天数 45 天，海运周期 35 天。必须在 3 月 15 日前完成备货，否则旺季断货。同时监测到竞品 A 当前库存紧张（购物车最多加 50 个），建议在 4 月加大广告抢占其断货窗口。"

## 四、关键决策场景：什么时候看什么数据？

| 运营场景 | 必看数据组合 | 决策动作 |
|----------|-------------|----------|
| **新品上架前** | 类目容量 + 竞品评论痛点 + 关键词机会 + 价格带 | GO / NO-GO 决策；定价策略；差异化卖点 |
| **日常运营周会** | 销售额 + ACOS + 转化率 + 库存天数 + 关键词排名变化 | 预算调整；页面优化；补货计划 |
| **销量下滑** | 流量（内部）+ 排名（外部）+ 竞品价格（外部）+ Review（外部） | 诊断是流量问题、转化问题还是竞争问题 |
| **广告 ACOS 飙升** | 广告报告 + 关键词排名 + 竞品广告动作 | 是否被竞品抬价？是否大词效果衰减？ |
| **库存积压** | 周转天数 + 库龄 + 竞品价格 + 类目趋势 | 降价清货 vs 站外 Deals vs 移除 |
| **被跟卖** | Buy Box 占有率（Keepa）+ 价格 + 订单量 | 开 Case + 降价守 Buy Box + 透明计划 |
| **准备旺季** | 历史旺季倍数 + 库存 + 物流时效 + 竞品库存 | 备货量计算；广告预算预分配 |

## 六、终极闭环：从数据到行动的自动化

结合内外部数据，构建更智能的闭环：

```
┌──────────────────────────────────────────────────────────────┐
│  感知层（内外数据融合）                                        │
│  • 内部：销售额↓15% + ACOS↑20% + 库存积压                     │
│  • 外部：竞品降价20% + 新品进入Top10 + 差评激增                │
└──────────────────────────┬───────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────┐
│  诊断层（AI 归因）                                             │
│  GPT-4 / 规则引擎判断："竞品价格战 + 产品痛点暴露"              │
└──────────────────────────┬───────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────┐
│  决策层（推荐动作）                                            │
│  ① 短期：开启限时 Coupon -15% 守住排名                        │
│  ② 中期：基于 Review NLP 结果升级产品（修复差评点）            │
│  ③ 长期：寻找差异化变体，迁移到细分长尾市场                     │
└──────────────────────────┬───────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────┐
│  执行层（人工/自动）                                           │
│  • 自动：调价脚本、广告预算调整                                 │
│  • 人工：产品开发、供应链谈判                                   │
└──────────────────────────┬───────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────┐
│  验证层（数据回传）                                            │
│  • 3 天后看：销售额是否回升？转化率是否改善？                    │
│  • 7 天后看：ACOS 是否回落？关键词排名是否恢复？                │
│  • 30 天后看：Review 评分是否回升？库存是否健康？               │
└──────────────────────────────────────────────────────────────┘
         ↓
   回到 PLAN，进入下一轮循环
```

### 闭环中的关键触发条件

| 监控指标 | 触发条件 | 自动动作 |
|----------|----------|----------|
| 毛利率连续 7 天 < 15% | 预警 | 触发成本审核流程 |
| ACOS 连续 3 天 > 30% | 预警 | 自动降低对应广告组竞价 |
| 库存周转天数 > 90 天 | 预警 | 推送清仓建议给运营 |
| 转化率 < 5%（类目均值 10%）| 预警 | 触发 Listing 质检任务 |
| 评分下降 0.2 星 | 预警 | 推送 Review 分析任务 |
| 大类排名下降 > 500 | 预警 | 检查竞品活动和价格 |

## 七、运营专家最关注的 10 个黄金指标

| 优先级 | 指标 | 数据来源 | 关注原因 |
|--------|------|----------|----------|
| 1 | **毛利率（真实）** | 内部 `gross_profit_percent` | 赚不赚钱是终极标准 |
| 2 | **自然流量占比** | 内部 `ads_sales_cny` / `price` | 健康的生意不依赖广告 |
| 3 | **核心关键词排名** | 外部爬虫 | 排名 = 自然流量 = 利润 |
| 4 | **转化率 vs 类目均值** | 内部 `convert_percent` + 外部类目均值 | 页面质量和产品竞争力 |
| 5 | **差评根因（NLP）** | 外部 Review 爬虫 + NLP | 知道问题才能修复 |
| 6 | **库存周转天数** | 内部 `inventory_turnaround_days` | 现金流和滞销风险 |
| 7 | **广告 ACOS（分词）** | 内部 `acos` | 精细化投放效率 |
| 8 | **竞品价格带变动** | 外部 Keepa | 市场竞争烈度 |
| 9 | **Buy Box 占有率** | 外部 Keepa | 有没有被跟卖/抢购物车 |
| 10 | **品牌搜索趋势** | 外部 Google Trends | 品牌心智建设进度 |
