# 卖家精灵全部场景分页网页实测

日期：2026-09-28

本轮使用已登录 Chrome 的卖家精灵账号，优先点击页面真实分页控件（`el-pagination`、HTML `pagination` 或“下一页”），只确认能否从第 1 页进入第 2 页、请求页参数是否变化以及结果是否变化。**本轮不测试是否能翻到 2,000 条以上**；2,000 条只记录为选产品/选竞品页面自身的访问提示，不能推广到其他场景。

请求证据只保留 endpoint、query 和 JSON body 的分页字段，不保存 Cookie、Token 或完整请求头。用户提供的关联流量和关键词反查 curl 是脱敏后按字段核对，未写入凭证。

## 结果矩阵

| 场景 | 页面/请求验证 | 第 2 页证据 | 结论与开发状态 |
| --- | --- | --- | --- |
| `product-research` 选产品 | 页面 `el-pagination` | 第 2 页结果与第 1 页不重叠；页面提示前 2,000 条 | 已有独立 `page/size` 全量实现；2,000 仅是本场景访问范围 |
| `competitor-lookup` 选竞品 | 页面 `el-pagination` | 100 条/页，第 1/2 页结果不重叠 | 确认 `page/size` 可翻页；不把 2,000 作为通用上限 |
| `keyword-miner` 关键词挖掘 | 页面 `el-pagination` | `pageNum/pageSize`；第 1 页 1–100，第 2 页 101–200 | 确认可翻页；高频词请求是查询级附加请求，只请求一次 |
| `keyword-reverse` 关键词反查 | 用户提供真实请求 | `limit=50, skip=450`，对应第 10 页；`market` 在 URL query | 确认 offset 翻页合同；页面样本本轮为 0 条，暂不开放 all |
| `traffic-source` 查流量来源 | 页面 `el-pagination` | `pageNo/pageSize`；20 条/页时第 1 页 1–20、第 2 页 21–40 | 确认可翻页；解析 `data.pager.items/total`，不强校验响应 pager 的 page/size |
| `association-traffic` 关联流量 | 用户提供真实请求 | `POST /v3/api/relation/traffic` 使用 `pageNum=7,pageSize=50` | 确认接口支持页码；payload 已修复为保留调用方 `pageNum`；暂不开放 all |
| `aba-research` ABA 数据选品 | 页面 `el-pagination` | 查询 `screen protector`，第 1 页 1–50；点击第 2 页后 URL `page=2`，结果 51–100 | 确认 `page/size` 可翻页；payload 不再强制第一页 |
| `keyword-comparison` 流量词对比 | 页面/源码核查 | 主结果需要 prepare 和最终变体列表；当前实现固定第一页 100 条 | 未确认可直接翻页；继续单页，待冻结动态列和变体上下文 |
| `traffic-extend` 拓展流量词 | 页面/源码核查 | 当前请求和导出链路固定 `page=1,size=100` | 未确认可直接翻页；继续单页，待确认 Unique Words/ASIN 辅助表跨页聚合 |
| `keyword-conversion-rate` 关键词转化率 | 页面/源码核查 | 当前请求固定 `pageNum=1,pageSize=100` | 未确认可直接翻页；继续单页，避免翻页重复计费 |
| `real-time-bidding` 实时查竞价 | 页面/源码核查 | 历史 taskList 有分页；SP/SB 业务详情当前固定第一页 | 仅任务历史列表确认有分页，业务结果未确认；继续单页 |
| `keyword-research` 关键词选品 | 页面 HTML 分页 | 点击真实“下一页”后 URL `page=2&size=50`；结果首行从 1 变为 51 | 确认 HTML 分页可用；当前包装不解析 total，暂不开放 all |
| `market-research` 选市场 | 页面 HTML `ul.pagination` | 点击页码 2 后 URL `page=2&size=50`；首个细分市场从 1 变为 51 | 确认 HTML 分页可用；当前包装不解析 total，暂不开放 all |
| `aba-reverse` 出单词反查 | 官方 XLSX 导出 | 无列表分页控件；导出接口不带 page/size | 单文件场景，不适用列表翻页 |
| `branddb` 全球商标库 | 官方 XLSX 导出 | 当前是导出请求，`pageNum/pageSize` 不能据此证明文件可分页 | 文件透传场景；分页参数语义待官方接口确认，不循环下载 |
| `listing-analysis` Listing Analysis | 单 ASIN 报告 | 无列表 rows/total，返回 task/report | 单报告场景，不适用列表翻页 |

## 请求合同摘要

| 合同类型 | 场景 | 页参数 | 结果路径 |
| --- | --- | --- | --- |
| JSON page | `competitor-lookup`、`aba-research` | `page/size` | 各自 `data.items`，`data.total` |
| JSON pageNum | `keyword-miner`、`association-traffic` | `pageNum/pageSize` | 分别 `data.items`、`data.pagerDto.items` |
| JSON pageNo | `traffic-source` | `pageNo/pageSize` | `data.pager.items`，total 优先 `data.pager.total` |
| JSON offset | `keyword-reverse` | `limit/skip` | `data.items`、`data.total` |
| HTML query/form | `keyword-research`、`market-research` | 字符串 `page/size` | 各自主结果表；当前未统一解析 total |

## 后续实施边界

已确认“能翻页”的场景仍只支持现有单页调用，除选产品外不自动循环请求。要开放 `collection_scope=all`，还需要该场景独立的 total/短页语义、唯一键、导出行数和恢复测试；不能因为请求字段与另一个场景相似就复用其分页逻辑。多页格式化与导出应逐页落盘、流式写入或使用有界聚合，避免同时保留所有原始响应和格式化副本。
