# 卖家精灵关键词转化率场景参数调研

## 结论

关键词转化率可以通过已登录浏览器页面捕获查询 JSON，并在本地生成第一页最多 100 条的业务工作簿。首期不调用官网 Excel 导出接口，但已使用官方 `KeywordConversionRate-US-wireless charger stand(123)-2026 Week 29.xlsx` 核对 33 列主表、工作表命名和视觉格式；本地不生成官方 `Notes` 页。

页面的关键词框不是普通多行文本框：每个词组必须按一次 Enter 变成标签。自动化必须把“动作超时”和“动作未生效”分开处理，不能在 Enter 超时后直接补按，否则可能产生重复标签或误触发页面行为。

## 页面与查询条件

- 页面：`https://www.sellersprite.com/v3/keyword-conversion-rate`
- 站点：美国、日本、英国、德国、法国、意大利、西班牙、加拿大、印度。
- 周期：`按周`（`W`）或 `近90天`（`90D`）。
- 关键词：1—1000 个词组；支持数组，或使用逗号、换行、制表符分隔的 TXT/Excel 按列粘贴文本；去空白、去重并保留首次出现顺序。
- 公共默认 `period=30d` 在本场景映射为页面默认的 `W`，因为页面不存在 30 天选项。

## 接口契约

页面查询调用：

- 方法：`POST`
- 路径：`/v3/api/keyword-conv`
- 主列表：`data.pager.items`
- 固定分页：`pageNum=1`、`pageSize=100`

请求体核心字段：

| 字段 | 含义 | 首期值 |
| --- | --- | --- |
| `market` | 站点代码 | 顶层 `site` |
| `timeType` | 周期 | `W` / `90D` |
| `keyword` | 批量关键词 | 规范化后以英文逗号拼接 |
| `bidMatchType` | PPC 匹配口径 | `exact` |
| `keywordMatchType` | 关键词匹配 | `all` |
| `matchType` | 查询模式 | `1` |

列表字段已验证包括关键词、时间节点、搜索/点击/购买量、搜索/点击转化率、PPC、CPA、产品均价、ACOS、广告预算、ABA 点击/转化集中度、前三 ASIN 及其点击/转化共享、搜索结果前十 ASIN。区间型字段按官方工作簿展开成最低、推荐或平均、最高三列。

## 安全页面交互

1. 先选择站点和周期，再清除页面残留标签。
2. 每个词组 `fill` 后只发送一次 Enter。
3. Enter 返回或抛出超时后，都以标签数量是否从 `N-1` 增加到 `N` 为事实依据。
4. 标签数已增加时视为提交成功，禁止补按 Enter。
5. 标签数未增加时直接失败，不继续输入剩余词组，也不点击查询。
6. 全部词组录入后校验页面占位文案 `已录入N/1000个关键词`。
7. 只点击一次“立即查询”；主请求缺失或状态不明时不做静默接口重放。

真实页面验证中，Enter 已经生成标签后，自动化动作仍可能因输入框占位文案改变而返回超时。这证明标签计数校验是必要的幂等边界。
