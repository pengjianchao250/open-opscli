# 亚马逊产品全维分析体系 — 第一步透视图构建方案

> **文档定位**：基于 opscli 现有 41 个数据集（1701 个字段），针对《亚马逊产品全维分析体系》中可立即落地的 **第一步（内部数据透视）**，规划可构建的透视图类型、维度与指标清单。
>
> **适用范围**：运营周会、日常监控、部门绩效考核、产品健康度诊断
>
> **版本**：v1.0

---

## 一、第一步构建原则

| 原则 | 说明 |
|------|------|
| **基于现有数据** | 仅使用当前 41 个数据集已有字段，暂不依赖外部采集数据 |
| **覆盖五维模型** | 优先覆盖分析体系中「内部经营」维度：销售财务、广告效率、流量转化、库存周转 |
| **可立即配置** | 所有字段均已在 dataset_fields.csv 中注册，可直接用于 BI 透视配置 |
| **分层设计** | 从「集团概览 → 部门/大组 → 销售小组 → 产品/ASIN」逐层下钻 |

## 三、透视图维度与指标明细

### 3.1 销售趋势多维透视

| 要素 | 内容 |
|------|------|
| **透视图目的** | 按时间、组织、产品、渠道维度监控销售额、订单量、销量的趋势变化 |
| **行维度** | `date_id`（日期，支持按日/周/月聚合）、`dept_name`（部门）、`large_team_name`（大组）、`team_name`（销售小组） |
| **列维度** | `platform_name`（平台）、`country_name`（国家）、`channel_name`（渠道）、`category`（品类）、`brand_name`（品牌） |
| **下钻维度** | `asin` / `parent_asin` / `ed_sku` / `product_name` |
| **核心指标** | `original_price`（销售额）、`price`（交易额）、`orders`（订单数）、`order_qty`（订单销量）、`order_qty_ds`（自发货销量）、`order_qty_dp`（平台发货销量） |
| **衍生指标** | 日均销售额、环比增长率、同比增长率、客单价（`price / orders`） |
| **过滤维度** | `date_id` 范围、`level_name`（等级）、`development_type`（开发类型）、`sku_type`（SKU等级） |
| **数据集** | `order_sale_trend_adv_traffic_inv_set` |

### 3.2 利润结构成本拆解透视

| 要素 | 内容 |
|------|------|
| **透视图目的** | 拆解每笔交易的成本结构，识别利润压缩点 |
| **行维度** | `dept_name`、`large_team_name`、`team_name`、`dev_team_name`、`category`、`brand_name` |
| **列维度** | `date_id`（月份）、`platform_name`、`country_name` |
| **下钻维度** | `asin`、`ed_sku`、`model` |
| **核心指标** | `gross_profit`（毛利）、`gross_profit_percent`（毛利率）、`purchase_cost`（采购成本）、`first_leg`（头程）、`freight`（运费）、`storage_charges`（仓租）、`advertising_fee`（广告费）、`fee`（手续费）、`tax_fee`（税金）、`fixed_cost`（固定成本） |
| **占比指标** | `purchase_cost_percent`（采购占比）、`first_leg_percent`（头程占比）、`freight_percent`（运费占比）、`storage_charges_percent`（仓租占比）、`advertising_fee_percent`（广告费占比）、`fee_percent`（手续费占比）、`tax_fee_percent`（税金占比）、`fixed_cost_percent`（固定成本占比） |
| **过滤维度** | `gross_profit_percent < 0.15`（亏损预警）、`date_id` |
| **数据集** | `order_sale_trend_adv_traffic_inv_set` |

### 3.3 退款与售后质量透视

| 要素 | 内容 |
|------|------|
| **透视图目的** | 监控退款金额、退款率、物料赔偿，定位高退款产品/渠道 |
| **行维度** | `date_id`（周/月）、`dept_name`、`team_name`、`country_name`、`overseas_origin_suffix`（产地） |
| **列维度** | `platform_name`、`channel_name`、`category`、`brand_name` |
| **下钻维度** | `asin`、`ed_sku`、`order_status`（订单状态） |
| **核心指标** | `refund`（退款金额）、`refund_percent`（退款占比）、`compensate`（物料赔偿）、`compensate_percent`（物料赔偿占比）、`resend`（补寄成本）、`resend_pkg`（补寄包裹数） |

| **过滤维度** | `refund_percent > 0.1`（高退款预警）、`date_id`、`country_name` |
| **数据集** | `order_sale_trend_adv_traffic_inv_set`（退款金额/占比） + `custom_refund_place_set`（退款明细/产地/订单状态） |

### 3.4 广告效率多维透视

| 要素 | 内容 |
|------|------|
| **透视图目的** | 从广告活动/广告组维度评估 ACOS、ROAS、CPC、点击率等核心广告指标 |
| **行维度** | `date_id`（日/周）、`campaign_name`（广告活动）、`ad_group_name`（广告组） |
| **列维度** | `ads_type`（广告类型）、`platform_name`、`country_name`、`area`（区域） |
| **下钻维度** | `asin`、`sell_sku`、`product_name` |
| **核心指标** | `ads_acos`（ACOS）、`ads_sales_cny`（广告销售额）、`ads_conversions`（广告销量）、`ads_clicks`（点击量）、`ads_impressions`（曝光量）、`ads_clicks_percent`（点击率）、`ads_cpc_percent`（CPC转化率） |
| **衍生指标** | ROAS（`ads_sales_cny / advertising_fee`）、CPC（`advertising_fee / ads_clicks`）、广告销售额占比 |
| **过滤维度** | `ads_acos > 0.3`（高ACOS预警）、`date_id`、`team_name` |
| **数据集** | `advertising_list_set` + `custom_type_advertising_list` |

### 3.8 库存周转健康度透视

| 要素 | 内容 |
|------|------|
| **透视图目的** | 监控库存周转天数，识别滞销品和断货风险 |
| **行维度** | `date_id`（周/月）、`ed_sku`、`product_name`、`pmc_code`（物控编码） |

### 3.12 产品 ASIN 健康度评分透视

| 要素 | 内容 |
|------|------|
| **透视图目的** | 对单个 ASIN 进行综合健康度评分，识别需要运营干预的产品 |
| **行维度** | `asin`、`parent_asin`、`product_name`、`brand_name` |
| **列维度** | `platform_name`、`country_name`、`date_id`（最新日期） |
| **下钻维度** | `sell_sku`、`ed_sku` |
| **核心指标** | `gross_profit_percent`（毛利率）、`convert_percent`（转化率）、`ads_acos`（ACOS）、`refund_percent`（退款占比）、`sell_qty_days`（周转天数）、`star`（星级）、`reviews_qty`（评论数）、`sessions`（流量） |
| **衍生指标** | ASIN 健康度评分（综合加权：毛利率×0.3 + 转化率×0.2 + (1-ACOS)×0.2 + (1-退款率)×0.15 + 星级/5×0.15） |
| **过滤维度** | 健康度评分 < 60（重点关注）、`gross_profit_percent < 0`（亏损）、`convert_percent < 0.05`（低转化）、`sell_qty_days > 90`（滞销） |
| **数据集** | `order_sale_trend_adv_traffic_inv_set`（核心经营指标） + `custom_crawler_listing_snapshot`（星级、评论数、排名） |

## 七、下一步建议

1. **优先配置前 3 个 P0 透视图**：销售趋势、利润结构、广告效率，覆盖运营周会的 80% 看数需求。
