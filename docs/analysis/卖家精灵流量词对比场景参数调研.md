# 卖家精灵流量词对比场景参数调研

> 调研日期：2026-07-30
>
> 正式场景标识：`keyword-comparison`
>
> 官方页面：<https://www.sellersprite.com/v3/keyword-comparison>
>
> 当前范围：默认“流量占比”、第一页 100 条、本地 XLSX。

## 1. 结论

流量词对比用于横向比较一个自己的 ASIN 与 1—10 个竞品 ASIN 的关键词覆盖、流量占比和流量词类型。场景已通过 `browser-route` 正式接入：先捕获并校验准备接口，默认选择“用畅销变体拓词”，用户也可明确选择“用当前变体拓词”，最后捕获主列表 JSON 并在本地生成 XLSX。

首期不调用官网有次数限制的异步导出，不自动翻页，也不支持自然排名、广告排名、转化效果和曝光位置等其他页面视图。

## 2. 输入参数

| 中文含义 | `params` 字段 | 规则 |
| --- | --- | --- |
| 自己的 ASIN | `ownAsin`；兼容 `myAsin` / `asin` | 必填且只能 1 个 |
| 竞品 ASIN | `competitorAsins`；兼容 `competitorAsin` / `asins` | 必填 1—10 个；不得包含自己的 ASIN |
| 站点 | 顶层 `site` | 默认 `US` |
| 变体拓词 | `variantSelection` | 可选 `sell_well` / `current`，兼容两个中文按钮文案；省略时默认 `sell_well` |

ASIN 支持列表、空格、中英文逗号、换行和制表符输入；统一转为大写、去重并保留首次出现顺序。每个 ASIN 必须是 10 位字母数字。

调用方不得传入 `diamondList`。该列表只能由官网准备流程产生。

## 3. 页面交互与接口顺序

### 3.1 准备接口

```http
POST /v3/api/keyword-comparison/prepare
```

页面填写两个输入框并点击“立即查询”后发起准备请求。运行时必须先校验：

- HTTP 状态；
- JSON 响应；
- `code` 和 `success`；
- `data.diamondList` 是否为非空字符串列表。

任一项失败都立即结束，不继续等待变体弹窗。成功后按 `variantSelection` 点击对应按钮：省略时默认“用畅销变体拓词”，用户明确要求时选择“用当前变体拓词”，无需再次确认。

### 3.2 主列表接口

```http
POST /v3/api/keyword-comparison/asin
```

默认流量占比请求形状：

```json
{
  "page": 1,
  "size": 100,
  "exactly": false,
  "orderColumn": 22,
  "desc": true,
  "asin": "B0949DWJCV",
  "asinList": [
    "B0949DWJCV",
    "B0744DM3Y3",
    "B0BRN58CXR"
  ],
  "station": "US",
  "sortAsin": ""
}
```

页面会根据准备结果生成最终 `asinList`；畅销变体模式可能以同父体下的畅销子体替换原始 ASIN。route handler 只允许该字段覆盖后端初始竞品列表，并严格校验数量、唯一性和 ASIN 格式，不强制最终列表包含原始 ASIN；页面分页、站点、排序和未知字段不能覆盖后端固定值。主请求不发送 `type=PERCENT`，也不发送 `diamondList`。

主响应监听只在目标变体按钮点击前启动，使用 120 秒超时，避免 prepare 和弹窗等待提前消耗预算。按钮点击失败与点击后主响应缺失使用不同错误码；页面交互后不使用浏览器上下文静默重放。

## 4. 响应字段

业务行位于：

```text
data.items[]
```

每个 ASIN 的动态对比值位于：

```text
item.competitorList[]
```

按 `competitorList[].asin` 匹配最终 ASIN，读取：

- `trafficPercentage`：流量占比；
- `trafficKeywordTypes`：流量词类型。

流量词类型映射：

| 枚举 | 中文 |
| --- | --- |
| `PRIMARY` | 主要流量词 |
| `PRECISE` | 精准流量词 |
| `PRECISE_LONG_TAIL` | 精准长尾词 |

公共字段包括关键词、关键词翻译、有效竞品数、ABA 周排名、月搜索量、月购买量、购买率、展示量、点击量、商品数和需供比。`gkDatas` 只用于商品展示，不作为动态对比值来源。

## 5. 本地 XLSX

文件名：

```text
CompareKeywords-{SITE}-{OWN_ASIN}-{YYMMDD-HHMMSS}.xlsx
```

工作簿包含：

1. 动态业务主表：每个最终 ASIN 生成“流量占比 + 流量词类型”两列，自己的 ASIN 标记 `(我的)`；
2. `ASIN` 辅助表：记录自己的 ASIN 标记和最终 ASIN 顺序。

流量占比输出为文本，例如 `6.86%`、`<0.01%`；购买率继续保留数值小数。工作簿不生成 `Notes`、宣传图片、公式、自动筛选、冻结窗格、合并单元格或 Excel Table。

## 6. 数据边界

- 固定第一页最多 100 条，`row_count` 是第一页实际行数，不是总匹配数。
- 首期只支持默认“流量占比”；页面上的自然排名、广告排名、转化效果和曝光位置仍未接入。
- 流量占比、搜索量、购买量等属于卖家精灵第三方估算或代理指标，不是企业自己的 Amazon Ads 曝光、点击、花费、订单、ACOS 或 ROAS。
- 接口和工作簿参考证据已脱敏，不包含 Cookie、Token、Session、账号或认证头。
