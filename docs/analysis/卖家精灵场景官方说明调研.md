## 调研口径

本文档用于逐场景记录卖家精灵官网页面的实际说明，为后续统一汇总和分析保留原始依据。

- 场景范围以 open-opscli 当前 `SellerSpriteScenario` 注册表为准，不把官网存在但当前未注册的页面纳入本轮清单。
- 官网记录必须来自已登录页面当前展示的文案与具体信息，尤其是每个场景的“温馨提示”。
- 对官网文案先做客观记录，不在单场景调研阶段扩展用法、推导结论或自行补充业务分析。
- 待所有已注册场景完成后，再单独进行跨场景汇总和统一分析。
- 本文档中的路由与流程类型只记录仓库已存在的注册信息；官网实际跳转情况在逐页调研时再核对。
- 官网功能名称按页面原文记录。“查竞品”等产品名称不代表其所有查询模式都能自动发现竞品，具体语义仍需结合输入方式、返回实体和变体关系判断。

## ABA 数据选品（`aba-research`）

- 官网：[ABA 数据选品](https://www.sellersprite.com/v3/aba-research)
- 页面标题：`ABA数据选品 - 亚马逊 ABA 数据选品工具 | 卖家精灵`
- 页面定位：`亚马逊ABA数据选品工具：基于搜索行为挖掘潜力产品`
- MCP 输入：父/子 ASIN 或关键词，注册表接受 `q`、`keywordOrAsin`、`keyword`、`asin` 中任一项。
- 页面输入提示：`输入父(子)体ASIN或关键词，如 B07Z82895W或iphone charger`。
- 页面推荐模式：热门市场、异动市场、持续增长市场、快速飙升市场、潜力市场、长尾市场。
- 页面可见表头：关键词、周排名/搜索趋势、周搜索量、现排名、历史排名、排名变化、排名变化率、展示量、点击量、PPC 竞价、SPR、标题密度、点击前三 ASIN、点击前三品牌。
- 页面规则提示：亚马逊在 2023-05-22 更新搜索频率排名规则；所选时间范围内具有相同搜索频率的搜索词显示相同数字排名，并按字母数字顺序排序。
- 快速入门：[aba-research-for-beginners](https://www.sellersprite.com/cn/help/aba-research-for-beginners)

### 温馨提示

1. ABA 数据选品是基于用户端源头的选品，直接反映买家的真实需求。
2. 设置搜索增长率 10% 为筛选条件，一份近期搜索排名飙升的关键词列表随即出炉。
3. 快速上手，建议观看新手上路图文或视频讲解。
4. 如有任何疑问，请先查看字段旁边的帮助问号，以及精心制作的教学视频。

## 出单词反查（`aba-reverse`）

- 官网：[出单词反查](https://www.sellersprite.com/v2/aba/reverse/search)
- 页面标题：`出单词反查 - 亚马逊出单词反查工具 | 卖家精灵`
- 页面定位：`亚马逊出单词反查工具：定位可能带来订单的搜索词`
- MCP 输入：1 至 20 个父体或子体 ASIN、Amazon 产品链接；注册表接受 `asin`、`asins`、`textareaValue`、`keywordOrAsin`、`q` 中任一项。
- 页面输入提示：`输入父(子)体ASIN(最多20个)或产品链接，多个以空格或逗号区分`。
- 页面可见周期：每周、具体周、月度。
- MCP 返回形式：官方 XLSX。
- 官方参考表头数：12，见 [`official-headers.json`](../../opscli/seller_sprite/reference/scenarios/aba-reverse/official-headers.json)。
- 快速入门：[aba-reverse-for-beginners](https://www.sellersprite.com/v3/knowledge/feature/aba-reverse-for-beginners)

### 温馨提示

1. 数据来源于亚马逊后台品牌分析中的关键词搜索报告，收录的是各关键词下点击排名前 3 的 ASIN。
2. 通过 ASIN 反查出单词时，只有当该 ASIN 进入对应关键词下点击排名前 3 时，这个关键词才会被收录进来。
3. 出单词反查与广告打通，通过优麦云，可一键反查广告相关 ASIN 的出单词。
4. 更多帮助信息，请参考右上角的“使用帮助”或“视频教程”，以及搜索结果页标题旁的帮助问号。

- 页面标题：`关联流量 - 亚马逊关联流量分析工具 | 卖家精灵`
- 页面定位：`亚马逊关联流量分析工具：发现产品关联曝光与引流机会`
- MCP 输入：`asin` 或 `asins`。
- 页面输入提示：`输入父(子)体ASIN(最多20个)，回车提交单个ASIN；或直接从txt或Excel按列复制粘贴`。
- 页面关联类型选项：VAV、CSI、AVP、BAV、MIB、FBT、MIE、BAB、COB、SP、FSA、BCA。
- 页面可见表头：产品信息、BSR 排名、关联类型、关联 ASIN、父/子销量趋势、父体销量、销售额、子体销量、子体销售额、价格、评分数、留评率、评分、月新增、配送、买家运费、上架时间、引流时间。

- 快速入门：[relation-keyword-for-beginners](https://www.sellersprite.com/cn/help/relation-keyword-for-beginners)

### 温馨提示

1. 输入 ASIN 即可一键查询产品及其变体的关联流量来源，了解产品的关联流量结构以及竞品流量布局。
2. 关联流量收录的是近 90 天内在 Listing 详情页关联流量位置曝光过查询 ASIN 的产品。
3. 关联流量主要分为相似产品关联、相关产品关联以及广告产品关联。
4. 关联流量与广告打通，通过优麦云，可一键查询广告相关 ASIN 的关联流量商品及流量占比。
5. 更多帮助信息，请参考右上角的“使用帮助”或“视频教程”，以及搜索结果页标题旁的帮助问号。

## 查竞品（`competitor-lookup`）

- 官网：[查竞品](https://www.sellersprite.com/v3/competitor-lookup)
- 页面标题：`查竞品 - 亚马逊竞品分析工具 | 卖家精灵`
- 页面定位：`亚马逊竞品分析工具：快速查看销量、BSR排名等产品数据`

- ASIN 查询口径：按用户给定的商品筛选记录，并可包含父子体或变体；它不能单独回答“给定 ASIN 的竞品是谁”。从 ASIN 发现竞品仍需结合流量词、搜索结果、关联关系或视觉相似结果。
- 页面操作：立即查询、复制 ASIN、自定义品类、加入产品库、导出、导出明细、列表/大图切换、自定义列。

- 快速入门：[competitor-lookup-for-beginners](https://www.sellersprite.com/cn/help/competitor-lookup-for-beginners)

### 温馨提示

1. 查竞品是查询竞争对手的销量以及其他核心数据，还可以查到对手最近几年的销量走势。
2. 当月月销量一般在下月月初上线。
3. 推荐使用卖家精灵插件查看竞品的产品数据。
4. 选市场已支持自定义品类，让市场分析的 Top100 样本更精准。

- 页面过滤分组：销售表现、产品信息、竞品筛选。
- 页面可见过滤项包括月销量、月销售额、子体销量、销量增长、BSR、变体数、价格、Q&A、评分、留评率、FBA 运费、毛利率、上架时间、LQS、包装重量/尺寸、卖家数量/所属地、品牌、卖家、关键词、配送方式、视频与商品标识。

### 温馨提示

1. 选产品就是选细分市场，因为市场发展不平衡，一般会寻找低竞争、高需求的潜力市场。
2. 基于资金实力、运营能力和供应链能力的不同，不同卖家的选品需求不同。
3. 系统内置了一些推荐选品模式，可以直接参考。
4. 选品前建议先选市场，或初步选出产品后再分析市场。
5. 选市场功能已支持自定义品类，让市场分析的 Top100 样本更精准。
6. 选产品与广告打通，通过优麦云，可一键洞察自身广告相关 ASIN 的市场表现。
