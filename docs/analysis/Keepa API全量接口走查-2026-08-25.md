# Keepa API 全量接口走查（2026-08-25）

## 结论

Keepa 官方当前文档列出 **13 个 endpoint、12 类 Response Object**。本仓库当前有 11 个可由 `keepa_run`/`opscli keepa run` 执行的 JSON 场景，覆盖 Product、Search、Finder、Deals、Best Sellers、Category、Seller、Seller Finder、Top Seller、Lightning Deals，即按“可执行查询场景”计算为 **11/13（84.6%）**。

这不等于全量支持：Graph Image 完全没有接入；Tracking 只有内部 Python Client/Service，没有公开 CLI/MCP 场景执行，但 Tracking 和 Notification 已提供可直接调用的 XLSX formatter；所有场景执行器目前都走 GET，官方允许 POST 的四个大 JSON 请求（Product Finder、Seller Finder、Browsing Deals、Add Tracking）未在场景执行链路启用。用户列出的 11 类 JSON Response Object 均有专用 formatter；Tracking Creation 是输入模型，Graph Image 是二进制 PNG。

本文的“支持”分三层：

1. **请求层**：代码能构造并发送官方合法请求。
2. **原始层**：Keepa 响应能在 `raw.json`/JSON v2 追溯。
3. **友好层**：对象字段、时间/金额/嵌套数组有专用 formatter 和明细 Sheet。

## Endpoint 合同与项目状态

所有 URL 均相对官方 Base URL `https://api.keepa.com/`，每次请求需 `key`。官方要求 HTTPS、接受 gzip；GET 适用于所有 endpoint，Product Finder、Seller Finder、Browsing Deals、Add Tracking 另外支持 POST。来源：[Making Requests](https://keepa.com/api-docs/request-basics.html)、[Overview](https://keepa.com/api-docs/)。

| Endpoint（官方路径） | 必选参数 | 可选参数/请求体 | 关键响应与官方限制 | 项目状态与缺口 |
|---|---|---|---|---|
| Product Request `/product` | `domain`；`asin` 或 `code` 二选一（逗号批量最多 100） | `stats`、`update`、`history`、`days`、`code-limit`、`offers`(20-100)、`only-live-offers`、`videos`、`aplus`、`rating`、`buybox`、`stock`、`historical-variations` | `products[]`；基础 1/商品；offers 每找到的 10-offer 页 6 token（无 offer 页成功为 5，刷新失败为 1）；`update=0` 可加 1，`update=-1` 缺失 ASIN 为 0；buybox/stock 各 +2，rating 最多 +1，historical-variations +1；`history=0`/`days` 缩减历史 | `product` 已接入并 formatter。**缺口**：`stats` 只按整数校验，官方还支持 `days` 或两个日期/毫秒时间戳区间；`update=-1` 被本地 `minimum=0` 拒绝；`code-limit` 官方要求正整数而本地允许 0。 |
| Product Search `/search?type=product` | `domain`、`type=product`、`term`（URL encoded） | `asins-only`、`stats`、`update`、`history`、`rating` | `products[]` 或 `asinList[]`；最多 20 结果；基础 10 token；update 每命中商品 0/1，rating 每商品最多 +1 且每次最多 +5 | `product-search` 已接入，Product Object 复用 formatter。**缺口**：`stats` 同样不支持官方日期区间。 |
| Product Finder `/query` | `domain`、`selection`（GET URL encoded，POST 为 JSON body） | `stats=1` | `asinList[]`、`totalResults`；`stats` 时 `searchInsights`；基础 10 + 每 100 ASIN 1，stats 另 30 + 每匹配 1,000,000 商品 1；默认/最小 `perPage=50`，page=0 可到 10,000，总分页上限 10,000；数组最多 50，过滤器 AND、数组内部 OR，至少一个过滤条件 | `product-finder` 已接入并开放透传 selection。**缺口**：空 selection 会被本地接受，但官方明确拒绝无筛选查询；场景执行链只 GET，未利用 POST。 |
| Browsing Deals `/deal` | `selection.domainId`、`selection.priceTypes`（只能 1 个且必须是有 deal 数据的类型） | selection 的 `page`、`dateRange`、类别/价格/排名/评分/卖家/属性等筛选；GET 或 POST | `deals[]`；每页最多 150，分页查询最多 10,000 ASIN；5 token/150 deals；错误 selection 为 bad request 且不消耗结果 token | `deals` 已接入，校验 domainId/单一合法 priceType。**缺口**：仅 GET，复杂 selection 可能触及 URL 长度；其余开放筛选字段不做本地 schema 校验。 |
| Best Sellers `/bestsellers` | `domain`、`category`（节点 ID 或 `websiteDisplayGroupName`） | `range=0/30/90/180`；`month`+`year`（必须成对，过去 36 个完整月）；`variations`；`sublist` | `bestSellersList`（含 `asinList[]`）；固定 50 token；根类目/产品组最多 500,000 ASIN，子类目最多 10,000；Brazil 不适用；无列表时空响应且不扣 token | `bestsellers` 已接入、校验日期和互斥关系，并 formatter。 |
| Category Lookup `/category` | `domain`、`category`（逗号 ID，最多 10） | `parents`（官方参数表要求显式值） | `categories[]`，`categoryParents`；每类目 1 token，`parents=1` 额外父树 token；无效/不存在类目按 endpoint error 语义返回 | `category-lookup` 已接入、默认 `parents=false`，Category formatter 已接入。 |
| Category Search `/search?type=category` | `domain`、`type=category`、`term` | 无官方额外参数 | `categories[]`；1 token/次 | `category-search` 已接入、formatter 已接入。 |
| Seller Information `/seller` | `domain`、`seller`（最多 100 个逗号 seller ID） | `storefront=0/1`；`storefront=1` 不能批量 | `sellers` map（key=sellerId）；seller 1 token；storefront 有数据时额外 9，ASIN 最多 100,000 并带 `asinListLastSeen[]`；不存在 seller 不扣 token，非法 ID 写入 error | `seller` 已接入，默认 storefront=false，formatter 已接入。 |
| Seller Finder `/sellerquery` | `domain`、`selection`（至少一个筛选；GET encoded/POST JSON） | paging/sort、`search`、`activeOnly`、seller/business/ratings/fulfilment/storefront/catalogue 等字段，`_gte/_lte` 范围；无 `stats` | `sellerIdList[]`；10 + 每 100 seller ID 1；最少/默认 50，分页最多 10,000；数组最多 50，结果为空仍扣基础 10；余额可变负 | `seller-finder` 已接入且校验非空 selection。**缺口**：场景执行链只 GET；通用站点归一化接受 Brazil(12)，但官方 Seller Finder domain 表不含 Brazil，应在场景层拒绝。 |
| Most Rated Sellers `/topseller` | `domain`（Brazil 不适用） | 无 | `sellerIdList[]`，按 rating count 排序，最多 100,000；固定 50 token | `top-seller` 已接入；无专用 Seller 列表二阶段联动，但原始/通用导出可用。 |
| Lightning Deals `/lightningdeal` | `domain` | `asin`（单个，指定时 1 token）；`state=AVAILABLE\|WAITLIST\|SOLDOUT\|WAITLISTFULL\|EXPIRED\|SUPPRESSED` | `lightningDeals[]`；指定 ASIN 1 token；无 ASIN 为过去 4 天全量，500 token | `lightning-deals` 已接入，支持 state/ASIN，formatter 已接入。 |
| Graph Image `/graphimage` | `domain`、`asin` | `types`（图 1/3 csv type+颜色）、或 `subranks`/`monthlysold`（图 2，二者与 types 互斥）；`range`、`yzoom`、`width` 300-1800、`height` 150-1800、`title`、`legend`、`lw` 0.5-3、`cBackground`、`cFont`、`cRanks`、`cMonthlysold` | 二进制 PNG，不是 JSON，不含 token envelope；1 token/图；相同请求按用户缓存 90 分钟；非法 type/颜色/混用图类型返回 bad-request image；API key 不得暴露在前端 | **不支持**：`KeepaApiClient` 仅 JSON，场景/CLI/MCP/文件结果均无二进制路径。 |
| Tracking `/tracking` | `type` 决定操作：`add`、`get`、`list`、`notification`、`listNames`、`remove`/`removeAll`、`webhook`；add 还需 Tracking Creation Object | 除 webhook 外可 `list`（最长 64）；`get/remove` 需 `asin`；list 的 `asins-only`、`page`、`perPage`≤100,000（不分页最多 500,000）；notification 的 `since`、`revise`、`all`、`readOnly`；webhook 的 `url`；add GET/POST，最多 3,000 对象 | `trackings[]`、`asinList[]`、`notifications[]`、`trackingListNames[]`；add 1 token/Tracking，其余 0；通知 24h 后删除，默认最多 2,000；tracking list 最多 100,000 个 | **内部部分支持**：`tracking/client.py` + `service.py` 覆盖全部操作，Creation 模型和显式确认/只读通知策略齐全；未注册公开 CLI/MCP，未做 formatter/审计。Service 另加受控 webhook host allowlist，因而不等同官方任意合法 HTTPS URL。 |

Product Finder/Seller Finder 的 selection 字段数量很大，官方页面是完整字段合同：Product Finder 包括类目、文本属性、尺寸重量、variation/image/video、Buy Box、缺货、coupon、布尔资格、seller、价格类型统计（`current_*`、`avg30_*`/`avg90_*`/`avg180_*`/`avg365_*`、`delta*`、`_gte/_lte` 等）；Seller Finder 包括 seller/business 身份、rating count/positive/neutral/negative、Buy Box/storefront/catalogue、`domainId`、paging/sort。项目当前采用开放 JSON 透传，这能兼容新增字段，但不提供完整类型/字段白名单校验。

### 嵌套参数展开

- **Product Finder `selection`**：分页/排序 `page`、`perPage`、`sort`；类目与文本 `rootCategory`、`categories_include/exclude`、`salesRankReference`、`title`、`manufacturer`、`brand`、`productGroup`；结构属性 `partNumber`、`model`、`color`、`size`、`edition`、`format`、`author`、`binding`、`genre`、`languages`、`publisher`、`platform`、`material`、`pattern`、`style`、`unitType`、`scent`、`itemForm`、`itemTypeKeyword`、`targetAudienceKeyword`、`brandStoreName`、`brandStoreUrlName`；尺寸/数量/媒体 `package*`、`item*`、`variationCount`、`imageCount`、`videoCount`、`variationReviewCount`、`variationRatingCount`；库存/Buy Box/卖家 `buyBoxStats*`、`outOfStock*`、`buyBoxIs*`、`buyBoxSellerId`、`sellerIds*`；数值过滤 `monthlySold`、coupon、flipability、businessDiscount、`current_<PRICE_TYPE>`、`avg30/90/180/365_<PRICE_TYPE>`、`delta30/90/deltaPercent30/90/deltaLast_<PRICE_TYPE>`、`lastPriceChange_<PRICE_TYPE>`、`backInStock_<PRICE_TYPE>`、`isLowest_<PRICE_TYPE>`/`isLowest90_<PRICE_TYPE>`；布尔资格 `singleVariation`、`hasParentASIN`、`hasReviews`、`isLowestOffer`、`isHazMat`、`isAdultProduct`、`isPrimeExclusive`、`hasAPlus` 等。所有 `_gte/_lte` 成对字段遵循官方价格/数值类型，数组最多 50 项。
- **Seller Finder `selection`**：分页/排序 `page`、`perPage`、`sort`、`minMatch`；搜索/身份 `search`、`activeOnly`、`domainId`、`sellerId`、`sellerName`、`businessName`、`isAmazon`；商业资料 `businessType`、`representative`、`vatID`、`tradeNumber`、`phoneNumber`、`email`、`address`、`addressCountry`、`customerServicesAddressCountry`、`hasBusinessDetails`；评分数量/正负中性比例及其 30/90/365/lifetime delta；活动、Buy Box、storefront、catalogue、offer/ASIN 计数的 `_gte/_lte` 字段。至少一个过滤条件必填，数组最多 50 项。
- **Deals `selection`**：必需 `domainId`、单元素 `priceTypes`；分页 `page`；时间 `dateRange`；类别 `includeCategories`/`excludeCategories`；评分/价格/排名/变化范围；`isLowest`、`isRisers`、`isDrop`、`mustHaveAmazonOffer`、`mustNotHaveAmazonOffer`；以及 `material`、`type`、`manufacturer`、`brand`、`model`、`color`、`size`、`unitType`、`scent`、`itemForm`、`pattern`、`style`、`itemTypeKeyword`、`targetAudienceKeyword`、`edition`、`format`、`author`、`binding`、`languages`、`brandStoreName`、`brandStoreUrlName` 等属性筛选。官方页面的字段/价格类型枚举是最终合同，本地不应把开放透传误认为完整校验。
- **Tracking Add body（Tracking Creation Object）**：`asin`、`ttl`、`expireNotify`、`desiredPricesInMainCurrency`、`mainDomainId`、`updateInterval`、`metaData`、`thresholdValues[]`（`thresholdValue`、`domain`、`csvType`、`isDrop`）、`notifyIf[]`（`domain`、`csvType`、`notifyIfType`）、固定 7 位 `notificationType[]`、`individualNotificationInterval`；官方允许单对象或最多 3,000 对象数组。项目模型已覆盖这些字段并校验主要边界。

## Response Object 支持

官方 12 类对象为：Product、Statistics、Marketplace Offer、Category、Deal、Best Sellers、Seller、Lightning Deal、Search Insights、Tracking、Tracking Creation、Notification。来源：[Response objects 总览](https://keepa.com/api-docs/)。

| 对象 | 项目现状 |
|---|---|
| Product、Statistics、Marketplace Offer | 已专用 formatter；历史、图片、变体、Offer、库存等拆明细 Sheet。 |
| Category、Deal、Best Sellers、Seller、Lightning Deal、Search Insights | 已专用 formatter 并由 manager 显式接入。 |
| Tracking | `tracking_formatter.py` 已提供主表、thresholdValues、notifyIf、notificationCSV 和未知嵌套字段明细；当前未接入统一场景执行器。 |
| Tracking Creation | `tracking/models.py` 输入校验和 JSON 序列化已接入，未作为响应 formatter。 |
| Notification | `tracking_formatter.py` 已提供主表、currentPrices、sentNotificationVia 和未知嵌套字段明细；preview 默认 `readOnly=1`，当前未接入统一场景执行器。 |

因此按用户列出的 11 类 Response Object，友好格式化为 **11/11**；Tracking Creation 是输入对象，不计入响应 formatter。原始响应保留范围大于格式化范围，未知字段不会从 `raw.json`/JSON v2 丢失；Tracking/Notification formatter 当前通过 Python API 暴露，尚未接入统一场景执行器。

## 通用响应、额度与错误

除 Graph Image 外，成功 JSON 通常含 `timestamp`、`tokensLeft`、`refillIn`、`refillRate`、`tokensConsumed`、`tokenFlowReduction`、`processingTimeInMs`，业务字段随后跟随 endpoint。`tokensLeft` 可因一次请求而为负；未使用 token 60 分钟过期。官方错误对象为 `error.type`、`error.message`、`error.details`，批量请求可能“整体 200 但 error 只描述失败项”，不代表全部结果失败。来源：[Making Requests](https://keepa.com/api-docs/request-basics.html)。

官方 HTTP 状态：200 成功；402 API key 无权限；405 参数超出允许范围；429 token 不足；500 服务端异常。非 200 响应仍带额度信息。项目 `KeepaApiClient` 能处理非 JSON、HTTP 错误、JSON `error` 并脱敏 API key，但当前将任何 200 响应中的 `error` 整体提升为异常，可能丢掉官方允许返回的批量部分成功数据；这是错误语义上的兼容性缺口。

## 优先级建议

1. **P0 合同校正**：实现 Product/Product Search `stats` 日期区间；允许 Product `update=-1`；将 `code-limit` 下限改为 1；Product Finder 拒绝空 selection；Seller Finder 拒绝官方不支持的 Brazil domain；保留批量响应中的业务数据和 error 明细。
2. **P1 传输完整性**：为 Product Finder、Seller Finder、Deals 增加 POST 选择或按 URL 长度自动切换，避免复杂 selection 被 GET URL 限制截断。
3. **P2 Graph Image**：独立二进制 client、MIME/PNG 文件结果和安全代理，不复用 JSON parser。
4. **P2 Tracking 产品化**：决定是否公开 CLI/MCP；若公开，补权限、审计、删除/消费确认和 Notification/Tracking formatter，并记录 webhook allowlist 是本地安全策略而非官方参数限制。
