# 四象限分类指南

## 分类标准

### X 轴：销售额（内部数据）

以品类中位数为界：
- **高**：> 品类销售额中位数
- **低**：≤ 品类销售额中位数

### Y 轴：问题率（综合指标）

问题率计算公式：
```
问题率 = (退款率 × 0.6) + (差评占比 × 0.4)
```

以品类中位数为界：
- **高**：> 品类问题率中位数
- **低**：≤ 品类问题率中位数

## 四象限矩阵

```
高问题率
    |
    |  红海     │ 高潜力
    | （销量高，│（销量低或
    |  高问题） │ 尚未布局，
    |           │ 低问题）
    |                    │
    |────────────────────┼────────────────────
    |                    │
    |  假趋势   │ 安全押注
    | （销量低，│（销量高，
    |  高问题） │ 低问题）
    |
低问题率 +──────────────────────────────────高销量
```

## 各象限特征与策略

### 安全押注（高销售，低问题）

- **特征**：市场已验证，产品成熟，客户满意度高
- **内部信号**：销售额高，退款率低，复购率高
- **外部信号**：评分高（> 4.3），评论数稳定增长，BSR 稳定
- **策略**：跟卖 + 微创新，优化成本结构
- **风险**：低
- **进入建议**：**GO** — 低风险跟进

### 高潜力（低销售或尚未布局，低问题）

- **特征**：新兴需求，供给不足，早期市场
- **内部信号**：无销售数据或销售额低
- **外部信号**：搜索趋势上升，卖家数量少，评分尚可
- **策略**：快速进入，抢占先机，建立品牌壁垒
- **风险**：中
- **进入建议**：**GO** — 差异化进入，抢占先机

### 红海（高销售，高问题）

- **特征**：市场大但竞争激烈，问题频发
- **内部信号**：销售额高，退款率高，投诉多
- **外部信号**：大量竞品，价格战激烈，评分低
- **策略**：避免进入，或需要大幅差异化
- **风险**：高
- **进入建议**：**NO-GO** — 除非有颠覆性创新

### 假趋势（低销售，高问题）

- **特征**：短期热点，不可持续，需求虚假
- **内部信号**：销售额先升后降，退款率飙升
- **外部信号**：BSR 剧烈波动，差评集中，搜索量骤降
- **策略**：完全忽略
- **风险**：极高
- **进入建议**：**NO-GO** — 坚决避开

## 分类决策流程

```
1. 获取 ASIN 的 internal_data（销售额、退款率）
2. 获取 ASIN 的 external_data（评分、评论情感）
3. 计算品类销售额中位数和问题率中位数
4. 判断销售额高低
5. 判断问题率高低
6. 定位到对应象限
7. 输出象限标签和策略建议
```

## 与机会评分的结合

四象限分类是机会评分的重要输入：

| 象限 | 基础评分加成 | 说明 |
|------|-------------|------|
| 安全押注 | +10 分 | 市场已验证，风险低 |
| 高潜力 | +15 分 | 先发优势，潜力大 |
| 红海 | -20 分 | 高风险，需特别谨慎 |
| 假趋势 | -30 分 | 几乎不应进入 |
