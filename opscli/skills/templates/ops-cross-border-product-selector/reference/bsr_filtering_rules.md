# BSR 健康度筛选规则

## 标准筛选（Standard）— 通用推荐

| 指标 | 最小值 | 最大值 | 说明 |
|------|--------|--------|------|
| subclass_rank | 100 | 5,000 | 已验证需求但非垄断 |
| reviews_qty | 300 | 1,000 | 已验证但有改进空间 |
| rating | 3.5 | 4.3 | 有质量提升空间 |
| price | $15 | $50 | 毛利空间充足 |

**适用场景**：保守跟卖、微创新、常规选品流程

## 宽松筛选（Loose）— 新品探索

| 指标 | 最小值 | 最大值 | 说明 |
|------|--------|--------|------|
| subclass_rank | 50 | 10,000 | 更广范围 |
| reviews_qty | 100 | 2,000 | 包含较新品 |
| rating | 3.0 | 4.5 | 包含改进空间大 |
| price | $10 | $80 | 更广价格带 |

**适用场景**：新品类探索、蓝海挖掘、早期进入

## 严格筛选（Strict）— 保守跟卖

| 指标 | 最小值 | 最大值 | 说明 |
|------|--------|--------|------|
| subclass_rank | 500 | 3,000 | 低风险区间 |
| reviews_qty | 500 | 800 | 已充分验证 |
| rating | 3.8 | 4.2 | 明确改进点 |
| price | $20 | $40 | 稳定价格带 |

**适用场景**：低风险投资、供应链能力有限、首次进入新品类

## 自定义筛选

可通过传入 `custom_rules` 参数自定义筛选规则：

```json
{
  "custom_rules": {
    "subclass_rank": {"min": 200, "max": 8000},
    "reviews_qty": {"min": 200, "max": 1500},
    "rating": {"min": 3.2, "max": 4.4},
    "price": {"min": 12, "max": 60}
  }
}
```

## BSR 与市场规模的对应关系（参考）

| BSR 范围 | 预估月销量 | 市场成熟度 |
|---------|-----------|-----------|
| 1-100 | 10,000+ | 成熟爆款 |
| 100-500 | 5,000-10,000 | 畅销品 |
| 500-1,000 | 2,500-5,000 | 稳定需求 |
| 1,000-5,000 | 500-2,500 | 已验证需求 |
| 5,000-10,000 | 200-500 | 小众需求 |
| 10,000+ | < 200 | 未验证/新兴 |

## 季节性风险提示

以下品类 BSR 波动大，需结合历史趋势判断：

- **Q4旺季**：礼品相关、冬季产品、节日装饰品
- **Q1淡季**：户外、花园、夏季产品
- **全年稳定**：厨房用品、家居收纳、宠物用品
- **突发热点**：口罩、消毒用品、居家办公（需特别警惕假趋势 False Trend）
