# 预警阈值参考表

## 默认阈值（全品类）

| 指标 | 健康 (>=80分) | 预警 (50-79分) | 危险 (<50分) | 说明 |
|------|--------------|---------------|-------------|------|
| gross_profit_percent | >= 20% | 10% - 20% | < 10% | 低于 0% 标红，需立即排查 |
| convert_percent | >= 10% | 5% - 10% | < 5% | 需对比品类均值 |
| ads_acos | <= 20% | 20% - 30% | > 30% | 新品可放宽至 35% |
| refund_percent | <= 5% | 5% - 10% | > 10% | 季节性产品需调整 |
| inventory_days | <= 45 天 | 45 - 90 天 | > 90 天 | 快销品应 < 30 天 |
| star | >= 4.3 | 4.0 - 4.3 | < 4.0 | 低于 3.5 需立即下架评估 |

## 品类差异化阈值（未来扩展）

| 品类 | convert_percent 健康线 | ads_acos 健康线 | refund_percent 健康线 |
|------|----------------------|----------------|---------------------|
| 电子 | 8% | 25% | 6% |
| 家居与厨房 | 12% | 20% | 4% |
| 服装 | 10% | 22% | 8% |
| 美容 | 11% | 18% | 3% |
| 体育 | 9% | 20% | 5% |
| 玩具 | 10% | 22% | 5% |

## 新品特殊阈值（上架 < 30 天）

| 指标 | 放宽后健康线 | 说明 |
|------|-------------|------|
| convert_percent | >= 6% | 新 Listing 需要时间积累评价和排名 |
| ads_acos | <= 35% | 新品期广告投入较高，允许更高 ACOS |
| refund_percent | <= 8% | 初期品控不稳定，适当放宽 |
| star | >= 4.0 | 评价数少，星级波动大 |

## 权重配置参考

### 默认权重

| 指标 | 权重 | 说明 |
|------|------|------|
| gross_profit_percent | 0.30 | 利润是核心指标，权重最高 |
| convert_percent | 0.20 | 转化率反映产品竞争力 |
| ads_acos | 0.20 | 广告效率影响利润空间 |
| refund_percent | 0.15 | 售后质量影响长期利润 |
| inventory_days | 0.10 | 库存健康度影响现金流 |
| star | 0.05 | 星级影响长期转化，但短期波动大 |

### 利润优先权重

适用于需要重点关注盈利能力的场景：

| 指标 | 权重 |
|------|------|
| gross_profit_percent | 0.40 |
| ads_acos | 0.25 |
| refund_percent | 0.15 |
| convert_percent | 0.10 |
| inventory_days | 0.05 |
| star | 0.05 |

### 增长优先权重
