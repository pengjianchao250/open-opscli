# ASIN 健康诊断 — 完整判断规则

本文件包含所有判断规则、阈值、例外、行动建议和边界条件。日常执行只需 SKILL.md 中的核心阈值表；需要完整规则时读本文件。

---

## 1. 评分等级

| 综合评分 | 等级 | 含义 |
|---------|------|------|
| >= 80 | Excellent | 健康度优秀，保持当前策略 |
| 60-79 | Good | 健康度良好，关注个别预警指标 |
| 40-59 | Fair | 需要关注，部分指标进入预警区 |
| < 40 | Poor | 需要立即干预，多指标严重 |

---

## 2. 单指标阈值（全品类默认）

| 指标 | 健康（>= 80 分） | 预警（50-79 分） | 严重（< 50 分） | 方向 |
|------|-----------------|-----------------|----------------|------|
| 毛利率 | >= 20% | 10%-20% | < 10% | 越高越好 |
| 转化率 | >= 10% | 5%-10% | < 5% | 越高越好 |
| ACOS | <= 20% | 20%-30% | > 30% | 越低越好 |
| 退款率 | <= 5% | 5%-10% | > 10% | 越低越好 |
| 库存周转 | <= 45 天 | 45-90 天 | > 90 天 | 越低越好 |
| 星级 | >= 4.3 | 4.0-4.3 | < 4.0 | 越高越好 |

**标准化逻辑**：线性插值。健康线 = 100 分，预警线 = 0 分，中间线性过渡。超出范围的按 100 或 0 截断。

---

## 3. 行动建议矩阵

### 毛利率

| 状态 | 行动建议 |
|------|---------|
| 严重 | 立即排查成本结构，重点优化采购成本和广告费 |
| 预警 | 评估采购成本谈判空间，优化广告 ACOS |
| 健康 | 毛利率健康，保持当前策略 |

### 转化率

| 状态 | 行动建议 |
|------|---------|
| 严重 | Listing 优化：主图 / A+ / 价格 / Review，排查流量质量问题 |
| 预警 | 优化产品页面，补充 QA，考虑降价或促销 |
| 健康 | 转化率健康，可尝试提价测试 |

### ACOS

| 状态 | 行动建议 |
|------|---------|
| 严重 | 紧急优化广告：暂停高 ACOS 词，加大精准匹配投入 |
| 预警 | 优化广告结构，降低大词竞价，增加长尾词 |
| 健康 | 广告效率良好，可适当增加预算扩大销售 |

### 退款率

| 状态 | 行动建议 |
|------|---------|
| 严重 | 紧急排查产品质量：分析退款原因，联系供应商改进 |
| 预警 | 关注退款趋势，优化产品描述减少预期差 |
| 健康 | 退款率健康，保持品质控制 |

### 库存周转

| 状态 | 行动建议 |
|------|---------|
| 严重 | 滞销风险高：考虑降价清仓或站外 Deals |
| 预警 | 库存周转偏慢，评估促销或调整补货节奏 |
| 健康 | 库存周转健康 |

### 星级

| 状态 | 行动建议 |
|------|---------|
| 严重 | 星级危机：分析差评原因，制定改进计划 |
| 预警 | 关注 Review 趋势，主动跟进差评客户 |
| 健康 | 星级健康，继续维护产品质量 |

## 4. 例外与特殊规则

### 新品（上架 < 30 天）

| 指标 | 放宽后健康线 | 原因 |
|------|-------------|------|
| 转化率 | >= 6% | 新 Listing 需要积累评价和排名 |
| ACOS | <= 35% | 新品期广告投入较高 |
| 退款率 | <= 8% | 初期品控不稳定 |
| 星级 | >= 4.0 | 评价数少，波动大 |

> 判断新品的方式：评论数 < 10 或上架日期距今 < 30 天。如果无法获取上架日期，使用评论数作为代理指标。

### 星级缺失

- 自动排除星级指标，将权重重分配到其他 5 个指标
- 在输出中标注"星级数据不可用"
- 不给缺失星级打 0 分或 50 分

## 5. 权重配置方案

### 默认权重（均衡）

| 指标 | 权重 | 说明 |
|------|------|------|
| 毛利率 | 0.30 | 利润是核心指标 |
| 转化率 | 0.20 | 反映产品竞争力 |
| ACOS | 0.20 | 影响利润空间 |
| 退款率 | 0.15 | 影响长期利润 |
| 库存周转 | 0.10 | 影响现金流 |
| 星级 | 0.05 | 短期波动大 |

### 利润优先

适用于需要重点关注盈利能力的场景：

| 指标 | 权重 |
|------|------|
| 毛利率 | 0.40 |
| ACOS | 0.25 |
| 退款率 | 0.15 |
| 转化率 | 0.10 |
| 库存周转 | 0.05 |
| 星级 | 0.05 |

### 增长优先

适用于新品推广期：

| 指标 | 权重 |
|------|------|
| 转化率 | 0.30 |
| ACOS | 0.20 |
| 星级 | 0.15 |
| 毛利率 | 0.15 |
| 退款率 | 0.10 |
| 库存周转 | 0.10 |

---

## 6. 优先行动排序规则

1. 按严重程度排序：严重 > 预警
2. 同级别按权重排序：权重高的指标优先
3. 多指标严重时标记为"需立即关注"
4. 行动建议分为 P0（严重）和 P1（预警）

---

## 7. 边界条件

| 条件 | 处理 |
|------|------|
| 所有指标都是健康 | 评分 100，输出"健康度优秀，保持策略" |
| 3+ 个指标严重 | 标记"多指标异常，建议全面复盘" |
| 毛利率为负 | 标记特殊异常"亏损状态，优先排查成本" |
| ACOS > 100% | 广告亏损，标记"广告花费超过广告收入" |
| 周转天数 > 365 | 长期滞销，建议清仓 |
| 星级 < 3.5 | 建议下架评估 |
| 单日/极短周期数据 | 提醒"数据周期过短，结论可能不稳定" |
| 跨站点/跨市场对比 | 不适用本评分公式（阈值和权重因市场而异） |

## 8. 新人常见误判

| 误判 | 正确理解 |
|------|---------|
| ACOS 高就停广告 | 先看转化率和搜索排名趋势，新品期 ACOS 高是正常的 |
| 退款率高就下架 | 先看退款原因分布，物流损坏可以改善包装 |
| 评分低就判定差 | 可能是新品期数据不足，需要看样本量 |
| 只看绝对阈值不看对比 | 始终对比团队/品类平均值，绝对阈值只是基线 |
| 库存多就不补货 | 要看销售趋势和季节性，旺季前备货是正常的 |
