# Dashboard Operation Standards

适用 Skill：`ops-dashboard-ai-bridge`。本文件只定义业务判断和页面修改约束；工具顺序、结果读取和错误处理见 `dashboard-tool-contract.md`。

## 模式与能力边界

- 页面下拉选择只调整处理优先级，不替代用户当前消息。
- 编辑偏好下，通过创建或调整图表完成页面目标，不调用 `ops-dataset-query` 获取真实数据。
- 数据分析偏好下，优先使用 `ops-dataset-query` 查询真实数据；用户目标同时要求页面变化时才组合编辑。
- 页面编辑只使用页面上下文、数据集目录和字段元数据，不把字段元数据当作真实业务数据。
- 用户明确要求只读时禁止写页面；任何模式都禁止生成、修改、上传或导出用户文件。
- 优先复用当前图表和数据集，只有现有页面不能承载目标时才新增图表。

## 数据集决策

1. 数据集和字段必须真实存在，并来自本轮页面工具结果；禁止猜测或手写 ID。
2. 搜索结果只有一个明确候选时可直接选用。多个真实候选会改变结果时，调用 `ask_user_question` 展示 2 到 4 个真实候选并等待选择；禁止只在正文中列选项、要求用户手输序号或替用户选择。
3. 同一轮组合新增的全部图表必须共享一个 `datasetId`。任一图表必须依赖第二数据集时，调整计划或停止，不跨数据集拼接。
4. 选定唯一数据集后必须先读取完整字段目录，再规划或写入图表；禁止先创建空图再试字段。
5. 修改既有图表的数据集时，重新读取目标数据集字段目录，不沿用原数据集、其他图表或历史轮次的字段。

## 字段与图表规则

- 字段必须属于本轮选定的数据集。
- 字段目录外层 `dimensions` 和 `metrics` 是字段真实角色：维度只进入允许维度的槽位，度量只进入允许度量的槽位，双角色槽位才允许两类字段。
- 展示和匹配使用 `title/key`；页面工具定位优先使用 `actionFieldId`，数字型字段操作按工具 schema 使用 `fieldId`。
- 字段定位器只提交真实 ID 和对应 `fieldSourceType`，不提交自行拼装的完整字段对象。
- 指标卡只配置 1 个度量。环形图只配置 1 个类别维度和 1 个度量。其他图表按本轮工具 schema 的字段槽位配置。
- 比率类指标必须明确分子、分母、统计粒度和筛选范围。口径无法确定时询问用户，不轮流尝试相似字段。
- 字段角色校验失败时，只允许根据同一份真实字段目录修正一次；仍失败则停止。

## 默认图表组合

用户指定图表类型时服从用户。未指定类型时按业务语义选择一个完整组合；无法唯一判断时询问用户，不自行删减或替换。

| 业务场景 | 图表类型与默认尺寸 |
| --- | --- |
| 营销/转化 | `indicator(w=4,h=16)`、`pie_circle(w=8,h=16)`、`combo_bar_line(w=12,h=30)`、`hbar_basic(w=12,h=30)`、`detail_table(w=12,h=30)` |
| 供应链 | `metric_trend(w=4,h=20)`、`hbar_basic(w=8,h=20)`、`bar_stacked(w=12,h=30)`、`detail_table(w=12,h=30)` |

组合中的 `w` 是默认宽度，`h` 是建议高度。默认组合不固定顺序、行或坐标。

## 布局规则

- 画布固定 12 列，不询问或接受其他列数。
- 默认组合只固定 `w`；模型结合当前画布和本轮全部图表判断期望 `x/y`。
- 最终布局必须满足 `x >= 0`、`y >= 0`、`w > 0`、`h > 0`、`x + w <= 12`，任意图表矩形不得重叠。
- 只提交工具 schema 声明的布局字段。批量创建若只接受 `w/h`，不得附加 `x/y`；创建后根据实际布局决定是否调用移动工具。
- 移动以页面返回的最终位置为准，不把请求坐标视为最终结果。

## 修改安全

- 组合创建必须原子、幂等并可回滚：写入前校验完整计划，任一图表失败时不得保留部分结果。
- 普通图表标题必须在创建计划中确定，去除首尾空白后长度为 1 到 100，不依赖创建后的补偿修改。
- `chart_id` 定向修改不能误改其他图表。已知目标时直接传目标 `chart_id`，不得把选择其他图表作为前置步骤。
- 标题、样式、位置、数据集和字段修改都必须保持非目标图表不变。样式一次只修改一个 `styleKey`。
- 字段重排只改变当前完整字段集合的顺序，必须保留聚合、排序、格式、筛选和重命名；增删字段使用对应增删或替换能力。
- 任何写入结果不确定时停止后续写入，按工具合同核验后再决定是否重试。

## 取数边界

用户要求查询真实业务数据、比较指标或解释业务原因时，加载并遵循 `ops-dataset-query`。Dashboard 工具负责页面编辑，数据集工具负责真实取数；不自行拼接查询参数、不直连接口、不用字段目录猜测分析结论。
