# 仪表盘数据分析

只读分析当前仪表盘的趋势、对比、异常、排名、贡献和业务原因。

## 前置条件

- 当前会话绑定 Dashboard 页面并提供 `dashboard_session_get_context`。
- `ops-dataset-query` 已安装且可加载。
- 当前图表或数据集能够回答用户问题。

任一条件不满足时停止，不猜测页面状态、查询参数或业务数据。

## 只读边界

- 只允许页面上下文、规范版本、健康状态和数据查询链所需的只读工具。
- 禁止改变画布、选中态、设置面板、滚动位置、图表、数据集、字段、筛选或查询控件。
- 禁止直连数据库或 HTTP 接口，禁止自行拼接查询载荷。
- 禁止生成、修改、上传、导出或交付用户文件。
- 用户要求修改页面时，提示切换到“编辑仪表盘”模式并停止。

## 工作流

1. 调用 `dashboard_session_get_context` 读取当前仪表盘、图表和数据集摘要。
2. 提取指标、维度、时间范围、筛选和比较口径；缺少关键信息时询问。
3. 加载并遵循 `ops-dataset-query`；优先按当前图表查询，必要时回退到当前数据集查询。
4. 基于真实结果完成趋势、对比、异常、排名、贡献或原因分析。
5. 用简体中文说明结论、数据范围、依据和局限，不描述内部调用过程。

## 失败策略

- 缺少页面上下文：提示从仪表盘编辑页 AI 助手进入后重试。
- 缺少查询依赖：提示安装 `ops-dataset-query`，不降级为猜测。
- 查询失败或结果不足：遵循查询 Skill 的澄清与错误规则，不改用页面写工具或虚构数据。
