# 接口参数与返回口径

2026-10-10 核对 [官方目录](https://openapi-doc.xiyouzhaoci.com/llms.txt) 中全部现行业务接口。查询仍通过 opscli MCP，不按官方 curl/Python 示例直连 API。相对日期及趋势范围另见 [趋势参数与可用日期](趋势参数与可用日期.md)。

## 构造请求前

先读取 `ext_xydc_openapi_operations` 对应操作的 `required_fields`、`payload_schema`、`example_payload`、`constraints` 和 `documentation_url`。schema 是构造指引，本地目前只检查必填字段；通过本地检查不代表供应商接受参数或已有数据。示例历史日期不作为默认周期。

- 国家通常支持 `US/CA/MX/BR/UK/DE/ES/IT/FR/JP/AU/SA/AE`，英国为 `UK`。小时排名仅 US/UK/DE；BSR 不支持 AU/SA/AE。
- 商品信息/流量快照使用 `entities=[{"asin":"...","country":"US"}]`；近30天订单使用 `asins=["..."]` 加顶层 country。日/周/月趋势与变体查询使用单个 `asin`，不混用这些结构。
- 兼容 Tool 的 `asins`、`keywords` 是字符串元素的 JSON 数组；通用入口分别使用 `entities`、`searchTerms`，不能直接复制旧参数名。
- `searchTerm` 是单词字符串；`searchTerms` 是词数组。`sort` 是含 `field/order` 的对象，order 只用 `asc/desc`。
- 列表接口显式传 `page/pageSize`，不省略或伪造服务端默认值。ASIN 反查例子从 page=1 构造；关键词分析官方未明确分页起点。兼容竞争 Tool 的用户页从1开始，目前 Provider 将其减1发给上游；通用入口的 page 原样透传，不能把两套页码混用。供应商分析分页基数待独立核实。

## 最近周期、分页与排序

| operation | 必填 payload | 补充 |
| --- | --- | --- |
| `asin_research_period` | asin、country、page、pageSize、period | period 仅 `last7days`；sort 可选，默认流量降序；没有 startDate/endDate |
| `asin_research_monthly` | asin、country、page、pageSize、startMonth、endMonth | 月份 YYYY-MM，周期最长一年；sort 可选 |
| `search_terms_info` | country、searchTerms、sort | 最近一周；sort 必填，兼容查词 Tool 自动传 weeklySearchVolume 降序 |
| `search_terms_analysis_period` | searchTerm、country、page、pageSize、period、sort | period 仅 `last7days`；sort 必填 |
| `search_terms_analysis_monthly` | searchTerm、country、page、pageSize、startMonth、endMonth、sort | 月份 YYYY-MM；sort 必填，未公开与反查相同的一年限制 |

排序字段按接口选择：

| 用途 | sort.field 枚举 |
| --- | --- |
| ASIN 反查日/月 | traffic、organicTraffic、advertisingTraffic、trafficAcquisitionRate、organicTrafficAcquisitionRate、advertisingTrafficAcquisitionRate、orRank、spRank |
| 关键词竞争分析日/月 | 上述8项，加 trafficRatio（ASIN流量占词总流量比） |
| 关键词最近一周信息 | clickConversionRate、searchTermCompetitiveDifficulty、organicRotation、searchFrequencyRank、weeklySearchVolume |

`orRank/spRank` 可用于自然/SP排名排序；请求排序名与响应嵌套字段名可能不同，不用 `totalRank`、`cpc` 等未经该接口枚举支持的名称。

### 反查词与月度竞争示例

```text
ext_xydc_openapi_call(
  operation="asin_research_period",
  payload={"asin":"B09XS7JWHH","country":"US","page":1,"pageSize":20,
           "period":"last7days","sort":{"field":"advertisingTraffic","order":"desc"}}
)

ext_xydc_openapi_call(
  operation="asin_research_monthly",
  payload={"asin":"B09XS7JWHH","country":"US","page":1,"pageSize":20,
           "startMonth":"2025-06","endMonth":"2025-06",
           "sort":{"field":"traffic","order":"desc"}}
)

ext_xydc_openapi_call(
  operation="search_terms_info",
  payload={"country":"US","searchTerms":["usb c cable"],
           "sort":{"field":"weeklySearchVolume","order":"desc"}}
)

ext_xydc_openapi_call(
  operation="search_terms_analysis_monthly",
  payload={"searchTerm":"usb c cable","country":"US","page":1,"pageSize":20,
           "startMonth":"2025-06","endMonth":"2025-06",
           "sort":{"field":"trafficRatio","order":"desc"}}
)
```

最近天竞争分析使用 `search_terms_analysis_period`，以 `period="last7days"` 替换月份字段，仍显式提供分页和 sort。分析通用示例的 page=1 是请求构造示范，未证明它是供应商第一页；兼容 Tool 的现有转换也不是官方分页基数已确认的证据。仅查询用户需要的页数；记录每页请求参数、返回条数和 `total`，遇到空页或已满足任务停止，不为凑满 total 无限翻页。未取全时标注“已返回部分”，不当作全部关键词/竞品。

## 明确的上限与站点例外

| 能力 | 官方约束 |
| --- | --- |
| ASIN 商品信息、流量快照、近30天订单 | 单次最多100个 ASIN，超过时按最多100分批 |
| 最近周关键词信息、ABA周趋势 | 单次最多100个词，超过时分批 |
| ASIN反查、关键词竞争列表 | 单次最多10000条；先取较小 pageSize，按需求翻页。兼容竞争 Tool 的 page_size 是1–100，默认20，通用接口不能沿用这个100上限 |
| ASIN月度反查 | 查询周期最长一年 |
| ABA周趋势 | 查询周期最长52周；不能推广到流量周趋势 |
| 小时排名 | 仅US/UK/DE，一次一天；多日确有需要才逐日查询 |
| BSR日趋势 | 来源Keepa，不支持AU/SA/AE |
| 商品信息日趋势 | coupon/promotion/subscription/other 仅US/UK/CA/AE/AU；其他字段支持通用站点 |

超限分批后按 ASIN+country 或关键词+country 对齐，不认为供应商结果顺序一定等于请求顺序。变体接口一次一个 ASIN，2026-08-12 更新已新增 AE/SA/AU；不能把它当批量接口。

## 返回指标的解释

- `trafficScore` 是供应商流量得分，不直接改名为真实点击、访客、会话或广告花费。订单接口返回 `orders`，称供应商订单量；未说明估算方法、销售件数或父子体汇总口径，不自行换算或累加变体。
- `rankTime` 保留原偏移及时点。`pageRank/totalRank` 可缺失，不能补0；官方未定义999哨兵或page=10等于未收录。只保留实际返回，缺失标“未返回”。
- 百分比/金额可能为数字字符串、null或非有限文本（例如反查增长率例子的 `Infinity`）。有限数值才做计算；null、缺失、Infinity不能补0或参加平均，保留原值并解释不可计算。单位不明确时不自动乘100或加货币符号。
- 关键词最近周可能返回 `costPerClick.value/minSuggestedBid/maxSuggestedBid`、`clickConversionRate`、`competitiveDifficulty`、`abaReport`；ABA周趋势则是 `cpc.value/min/max`、`searchTermCompetitiveDifficulty`、`organicRotationRate`、`adjustedClickConversionRate`。读取具体操作的字段，不能按一套名字套用全部响应。
- ABA竞争难度越大表示竞争越激烈；自然轮动率和调整后点击转化率以小数形式给出，可将有限小数乘100展示为百分比，并注明换算。新增指标和CPC无数据时为null，不当作0。
- 商品价格保留实际返回的 currency；CPC页面没有明确货币合同，不统一标成美元。周流量可能返回 week 或 dateRange，展示位字段也有 schema/例子差异，保留真实响应中的字段。

## 调用节奏、Credit与公开能力

v2官方默认按40次/分钟设计节奏。批量/分页应有任务范围，不并发无限拉取；Provider已处理有限网络/5xx/429重试，Agent不再叠加重放。失败按项目反馈规则记录原始区间、错误和trace_id。

| 接口组 | 文档Credit估算 |
| --- | --- |
| ASIN商品/流量快照 | 每ASIN 1 |
| ASIN日趋势（基础、广告、BSR、商品、流量） | 每10天向上取整1 |
| ASIN流量周/月 | 每4周向上取整1 / 每月1 |
| 月订单 / 近30天订单 / 变体 | 每6月向上取整1 / 每5 ASIN向上取整1 / 每请求5 |
| 词流量日、排名日 / 排名小时 | 每5天向上取整1 / 每天固定3 |
| 反查词、关键词竞争列表 | 每返回20条向上取整1 |
| ABA周 / 最近周关键词信息 | ⌈词数÷20×周数⌉ / 每10词向上取整1 |

这些是预估规则，实际消耗以返回 `cost_credits` 为准；费用字段缺失不推测，错误也不保证免费。`client_quota` 官方只适用于v1，不是v2公共工具；2026-08-06已下线市场洞察API，不能按旧Release Notes添加可用日期/市场接口。
