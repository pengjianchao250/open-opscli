# 历史订单与类目排名

用于“从开售至今逐月销量、父体销量、Hand Trucks 等小类目月均排名、输出 Excel”等需求。先按主 Skill 检查 CLI/MCP 入口并读取操作目录；这份说明不保证供应商覆盖从开售以来的全部历史。

## 对象与周期

1. 从 Amazon URL 的 `/dp/` 或 `/gp/product/` 提取 ASIN，按域名确认站点。同一 ASIN 去重，同时保留用户原链接。
2. 用 `asin_info` 查询商品信息；需要父体口径时用 `asin_variations` 查询父子体关系，保留实际返回的父体和子体 ASIN。开售日期只有在真实返回且含义明确时才使用；抓取日期、首次观测日期不能直接改名为开售日期。
3. 月度订单使用 `asin_orders_trends`，payload 为 `asin/country/startMonth/endMonth`，月份格式 `YYYY-MM`。`asin_orders` 只提供近 30 天订单量，不能替代历史月数据。
4. 类目日排名使用 `asin_bsr_daily`，payload 为 `asin/country/startDate/endDate`。请求跨度、站点例外和日期恢复按目录及 [趋势参数与可用日期](趋势参数与可用日期.md)；计费单位不是最大查询跨度，不臆造固定日期上限。

用户指定从开售至今时，区分要求的范围与供应商实际返回的范围。没有明确开售日期或历史起点时，说明目前可确认的边界；必要时补问起始月份。当前未结束月份标为“截至已返回日期”，与完整月份分开解释。部分历史缺失不填零，不通过逐日试错探测最早数据。

## 父体与类目口径

- 官方月订单返回 `orders`，未明确父子体汇总和销售件数口径。父子体关系已确认也不证明查询父 ASIN 得到全父体销量。结果标为“供应商返回的 ASIN 月订单量”；只有真实合同或响应明确父体汇总时才标为父体值。子体失败不能据此更换父体重复试错，也不自行累加多个变体冒充父体销量。
- 从实际响应识别目标小类目的名称和 ID，例如 Hand Trucks。按同一类目 ID 筛选有效日排名，再分自然月计算平均值；不混合主类目、多个小类目或关键词自然/广告排名。无法匹配目标类目时标为“未返回目标类目排名”。
- 对每月有效排名计算算术平均，展示有效天数、首末数据日与缺失情况。返回有一天多条观测时，先确认日值口径；无法确认则标明采样平均，不宣称全月每日平均。缺失/null/非有限数值排除计算且保持缺失，不补零。

## Excel 交付

西柚通用查询返回 JSON，没有 Keepa 的服务端 `job_id/export` 工作流。CLI 可通过 `--output` 保留完整响应，再使用可用的表格 Skill 或本地表格库生成工作簿；远端动作仍通过正式 CLI/MCP。

建议工作簿包含月度汇总、订单原始明细、排名日明细和口径说明。汇总保留请求 ASIN、确认的父体 ASIN、country、月份、供应商月订单量、目标类目 ID/名称、有效排名天数、月均排名与覆盖状态。原始明细保留请求周期和返回数据来源，记录实际 `cost_credits`；失败保留原始错误及反馈 UUID，不生成看似完整的零值历史。只要取得部分有效数据，就交付这些数据并清楚说明缺口。
