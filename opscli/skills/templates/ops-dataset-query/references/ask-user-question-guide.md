# 模式感知澄清规划器

只在 `SKILL.md` 的歧义预检命中、用户必须做选择时使用结构化提问。用户确认前不构造或执行查询。

## 候选权威

- CLI-only 候选只来自当前账号已刷新的 planner/guidance。元数据所有权或数据状态不明时，先刷新/升级，再重新规划。
- MCP-only 候选只来自本请求链 `query_metadata`。认证或远程元数据失败时停止；禁止本地搜索或读取 CSV，也不使用先前请求或其他账号的输出。
- 一次请求固定一种模式。不合并、不补齐、不切换候选来源。

## 展示规划器

自然语言候选展示只包含中文名称、中文说明、业务粒度和口径差异。技术 key 仅内部使用，或在用户明确提供精确完整技术标识时用于精确响应。不要求自然语言用户阅读、选择或回复内部标识。

- 数据集候选：展示中文名称、业务粒度、适用场景和主要口径差异。
- 字段/指标候选：展示中文名称、含义、单位、币种、明细/汇总口径和公式差异。
- 人员/组织候选：展示中文角色和层级，例如部门、大组、小组、销售或开发。
- 候选过多时先展示可扫描的中文列表，再提供 2-3 个最相关快捷选项，并保留自由输入。

## 必须澄清的歧义

### 数据集与字段

当两个以上授权候选都能表达用户需求，或综合/细分、明细/汇总、业务角色、单位、计算口径不同时，展示差异并让用户选择。候选为空时如实说明当前授权范围无候选，不扩大范围。

### 时间与对比

“最近一个月”、“最近一周”、不等天数跨期对比，或缺少主周期/对比周期时，给出可核对的绝对起止日期候选并澄清。“近 N 天”可按包含当天计算，但执行前必须展示绝对日期。

### 币种

当已选数据集同时提供原币和 CNY 候选时，不论用户是否主动提到币种，都必须澄清。选项说明币种、换算口径和适用场景；不静默选择任一币种，也不跨币种相加。

### 筛选枚举

用户明确筛选值不在当前账号组件枚举中时，展示该组件本次返回的中文可用值。组件 alias 缺失时只阻断该筛选，不引入替代来源。

## 查询前确认

执行前使用中文业务摘要确认：

- 数据集中文名称和粒度。
- 时间范围、是否包含当天、主周期和对比周期。
- 维度、指标、公式/聚合口径和币种。
- 筛选中文名称、操作符、用户确认值、排序和行数。

仅当用户明确提供精确完整技术标识时，确认摘要才可回显该标识；其他情况保持中文业务展示。

## 纠错

0 行或主要指标为空时如实说明已确认范围，提供进入 `ops-query-wizard` 的纠错选项。用户明确说结果、字段、筛选、排序或行数不对时，直接移交纠错，不在当前 Skill 猜测性重试。
