# 结果分析规划器

输出严格按以下五节排列；没有足够证据的节可写“未发现”或“无法判断”，但不得省略。

## 范围与口径

- 说明数据集中文名称、时间范围、维度、指标、筛选、币种、聚合和排序。
- 说明返回行数；若结果不完整，注明总行数、已展示行数和取得完整结果的方式。
- 区分主周期与对比周期，并说明任何公式字段使用的汇总或明细表达式。
- 原币金额按币种分开汇总；不得混加不同原币，也不得把原币列与人民币/CNY 列混加。

## 主要结论

- 每个数值、排名、比例、增减或趋势结论必须紧跟可核对的字段名或结果列，例如“`$RESULT_COLUMN` 为查询返回值，来自结果列 `$RESULT_COLUMN`”；占位符必须替换为本次实际结果列。
- 仅根据已返回的行作结论；未查询的维度、周期或分组不能外推。
- 描述相关性或同时变化时不得宣称因果；因果需要独立实验、归因规则或用户提供的外部证据。

## 关键贡献/异常

- 指出贡献最高、变化最大、缺失、零值或离群的行，并给出该行的维度值、字段名或结果列和计算方式。
- 返回行存在但主要指标全为 0 时，只能说明全零事实；全零不等于无数据，不得据此断言业务已暂停。
- 对环比/同比使用返回的当前、`last_*`、`diff_*`、`pct_*` 结果列；缺列时明确说无法据此比较。
- 不把排序靠前、样本过小或单期波动表述为已证实的业务原因。

## 可执行观察

- 提供与证据直接对应的下一步观察、复核或筛选建议，区分事实与建议。
- 建议复核时指出需要增加的字段名、维度、时间范围或权限组件；不要虚构未返回数据。

## 限制

- 披露时间滞后、账号权限、筛选口径、缺失值、公式口径和样本范围等限制。
- 空值不等于 0；需披露数据更新时间或快照时间，缺失时不得声称结果代表查询时刻的实时数据。
- 任何截断必须说明排序字段、截断数量和总行数；禁止隐藏截断，也不能把 Top N 当成全量。
- 若结果为 0 行或主要指标为空，说明该事实和已用筛选，不凭空判断业务表现。
